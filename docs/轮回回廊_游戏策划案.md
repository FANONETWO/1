## 一、项目定位

| 项 | 内容 |
|---|---|
| 产品名 | 轮回回廊（工程目录 `infinite_loop`，Godot 主场景 `main_menu.tscn`） |
| 引擎 | Godot 4.7.2 · GL Compatibility · 1280×720 · `canvas_items` 缩放 |
| 美术方案 | **零外部资源**：等距菱形地图、角色菱形块、全部 UI 均由代码绘制 |
| 规则蓝本 | 无限恐怖 2.5RE V1.04（系统主蓝本）＋ 雪版 2.3／FX v1.40／圈版 1.04／RM 正式版（题材与兑换框架） |
| 单局时长 | 15–20 分钟（一个副本，含建卡与主神空间循环） |
| 目标用户 | 无限流小说读者、TRPG 骰池规则爱好者、单机 CRPG 玩家 |

**一句话定位**：你是被主神扔进恐怖片的轮回者，靠 D10 骰池、行动点战术与基因锁，在《惊变公寓》里活着离开。

**三大体验支柱**

1. **骰池的紧张感** —— 每枚 D10 独立判定，≥8 才计成功，掷出 10 还能加骰；高属性也不保证成功（附加成功不能救活 0 成功）。
2. **基因锁的爆点** —— 生命掉到 30% 以下自动觉醒，首次致死触发「绝境爆种」起死回生；这是本作招牌爽点。
3. **主神空间的成长仪式感** —— 结算 → 奖励点 → 兑换 → 下一场影片，形成「活着回来就有变强」的正反馈。

## 三、核心玩法循环

### 3.1 大循环（Meta Loop）

```
主菜单 ──新的开始──▶ 建卡 ──▶ 主神空间 ──进入影片──▶ 副本 ──结算──▶ 主神空间 ──▶ …
   ▲                              │                                    │
   └────────继续（读档）──────────┘                           奖励点 + 最佳评价入库
```

**目标改造**（见路线图 M2）：主神空间补上「休整 10 天」与「影片简报」，让「回来」和「出发」都有明确节拍。

### 3.2 副本内循环（Micro Loop）

```
进入公寓 ─▶ 等距地图点击移动 ─┬─▶ 调查点：拿物资 / 触发检定（D10 vs DC）
                              ├─▶ NPC 对话：条件选项 + 检定分支拿情报
                              ├─▶ 遇敌：相邻点击 → 切入战斗场景（AP 回合制）
                              │        └─▶ 胜利返回探索（战果跨场景保留，敌人不复活）
                              └─▶ 集齐钥匙 → 踩出口 → 三结局结算
```

### 3.3 节奏曲线（单局 15–20 分钟）

| 阶段 | 时长 | 情绪 | 关键设计 |
|---|---|---|---|
| 开场 | 1 min | 悬疑 | 轮回手表派发任务（INTRO 文本） |
| 探索前段 | 4 min | 谨慎试探 | 调查点给钢管 / 线索 / 药柜钥匙 |
| 首次遭遇 | 5 min | 紧张 | 丧尸战斗教 AP 与骰池；爬行者教距离 |
| 支线抉择 | 3 min | 道德张力 | 陈叔要药 ↔ 阿贵给尸王弱点 |
| 尸王战 | 5 min | 高潮 | 首次致死 → 绝境爆种（招牌演出） |
| 撤离结算 | 2 min | 宣泄 | 三结局 + 奖励点清单 |

## 四、系统设计规格

### 4.1 角色与建卡

| 项 | 规格 |
|---|---|
| 属性 | 9 项，建卡区间 1–6，池 27 点；升级成本 = 从当前值累加到目标值（1→3 花 2+3=5） |
| 技能 | 12 项，建卡 0–5，池 20 点（1 点/级） |
| 天赋 | 5 选 1，各给 2–3 项技能 +1 与一条 tag 被动 |
| 派生 · 生命 | 耐力 × 4（「老练幸存者」+4） |
| 派生 · 意志 | 决心 + 沉着 |
| 派生 · 防御 | 敏捷 + 躲藏÷2（向下取整）+ 护甲 + 基因锁一阶 +1 |
| 派生 · 先攻 | **现状** d10 + 敏捷 + 沉着；**目标**改为骰池判定 + 附加成功（见 M1） |

### 4.2 检定系统（D10 骰池）

- **DP** = 属性 + 技能 + 调整值；每枚 D10 **≥8 计 1 成功**。
- **10 加骰**：掷出 10 追加一骰，可递归；加骰等级最低为 8（预留「9 加骰」接口给武器/天赋）。
- **附加成功**：属性 ≥6 得 1 个、每 +5 再加 1；技能达 5/7/9/11/13/15 各 +1。
- **门控规则（本轮还原）**：掷骰成功数为 0 时，**再多附加成功也不能让行动成功**（re25《核心规则》「附加成功的使用」）。
- **0 级惩罚**：生理 −1 成功、心智自动失败、互动 −2 成功。
- **判定**：成功数 ≥ DC 即通过；意志力可在战斗外检定投入 1 点换 +1 成功。
- **待补**：对抗检定（DC = 对方成功数，平局投机运骰）、机运骰（0 DP 时只有 10 算成功）、协助、周期检定。

### 4.3 战斗系统

| 项 | 规格 |
|---|---|
| 回合结构 | 先攻排序 → 轮流行动，每回合 6 AP |
| AP 消耗 | 移动 1 格 1 AP · 攻击 3 AP · 防御姿态 2 AP（+2 防御）· 使用物品 2 AP |
| 攻击 | DP = 力量 +（肉搏/白刃）或 敏捷 + 枪械；远程需弹药（手枪 12 发） |
| 伤害 | `max(1, 攻击成功数 − 目标防御) + 武器伤害 + 天赋/基因锁加值 − 目标护甲` |
| 武器 | 拳头 1 · 钢管 2 · 开山刀 3 · 手枪 3（射程 4）——**本轮修复：武器伤害此前未被结算读取** |
| 防御 | 防御值 + 姿态 2 点；首轮未行动者措手不及（**待实现 −2**） |
| 敌人 AI | 贪心逼近（曼哈顿距离），进入射程即攻击；1 回合内移动后就地攻击 |
| 相持 | 战斗失败 → 陨落结局；胜利 → 击杀奖励点回传探索场景，死者不复活 |

### 4.4 基因锁

**已实现（现状）**

- 生命 ≤ 30% 自动觉醒**一阶**：攻击 +1 成功、伤害 +1、防御 +1（防御项本轮补齐）。
- **首次生命归零触发「绝境爆种」**：觉醒基因锁并恢复 20% 最大生命；已觉醒后再归零则真正死亡。

**目标设计（分阶蓝图，依据三版规则书）**

| 阶 | 效果 | 开启 | 代价 |
|---|---|---|---|
| 一阶 | 全检定加值、全技能视为 1–2 级 | 生命 ≤30%（保底）或主动冲锁 1D10≥10 | 维持轮数 = min(耐力, 沉着, 决心) |
| 二阶 | 选一生理属性 +6、相关检定 +2 附加成功、维持翻倍 | 一阶满熟练（9 点）＋ 2D10≥18 | 每轮 3 点意志，超时每轮 2 点剧痛 |
| 三阶 | 模拟熟悉者的心智/社交属性与技能 | 剧情＋高阶判定 | 显著 XP 消耗 |
| 四阶 | 基因控制（意志换属性）＋ 入微；中期免疫心灵与抹杀 | 终局解锁 | 心魔／失控风险 |

> 设计取舍：规则书「首次开锁只给一次性超常表现、不会回血」，本作保留「爆种回 20% 生命」作为招牌爽点，但把「何时开锁、开多久」的代价体系列进 M3，避免零成本爆发。

### 4.5 意志力

- 上限 = 决心 + 沉着，初始满值，目前仅 `镇定剂`（+3）可恢复。
- **可用场景（现状）**：战斗外检定投入 1 点换 +1 成功。
- **缺口**：战斗中意志力毫无用途，导致「决心/沉着」在战斗里近乎废属性。**待实现**（M1）：每回合限 1 次，投入 1 点换取「本次攻击 +1 成功」或「本回合防御 +1」。

### 4.6 主神空间

| 功能 | 现状 | 目标 |
|---|---|---|
| 角色档案 | 属性/技能/背包/基因锁状态 | 保留 |
| 奖励点 | 结算累计 | 保留 |
| 最佳评价 | 显示中文结局名（本轮修复） | 保留 |
| D 级兑换 | 属性（当前值×80 分）· 技能（0→1 90 分，之后 60 分）· 7 件装备补给 | 价格对齐规则书（属性×100、技能递增） |
| 副本卡 | 固定 1 张「惊变公寓」 | 影片列表（1 可进 + 2 锁定灰卡） |
| 休整 | **无** | 「休整 10 天」：免费全恢复 1 次，追加恢复按分计费（M2） |
| 影片简报 | **无** | 进入前 overlay：主线/支线/危险评级（M2） |

**规则书依据**：每场影片后回主神空间停 **10 天**（re25《主神空间》），入场有光罩过渡（1–3 分钟）；D/C/B/A/S 是**支线/资源分级**（3D=1C）而**不是影片难度分级**，影片难度随小队实力浮动。本作单机切片保留「固定卡片 + 奖励点」的简化经济。

### 4.7 副本「惊变公寓」

- **主线「活着离开」**：值班室药柜拿钥匙 → 踩出口撤离（20 分）。
- **支线「老邻居」**：降压药交陈叔 402 → 获得尸王弱点情报（10 分）。
- **支线「清道夫」**：击杀尸王（25 分）。
- **线索 5 条**：储物间便条 / 值班表 / 床垫匕首 / 工作日志 / 尸王弱点（每条 +5 分）。
- **结局判定**：完美撤离 = 撤离 + 完成两条支线 + 线索 ≥3；惊险撤离 = 活着离开；陨落 = 任务失败，本次奖励清零。
- **结算公式**：`总分 = 任务分 + 击杀分 + 线索数 × 5`。

### 6.3 设计风险

1. **单副本的重复可玩性**：当前只有一张地图一个结局分支树，二周目缺乏变化 → 需要「影片列表 + 随机线索点 + 难度浮动」。
2. **爽点与代价失衡**：基因锁零代价 → 玩家没有「何时开锁」的决策，爆发变成无脑收益。
3. **奖励点经济单薄**：只有 7 件固定商品 + 属性/技能线性加价，中期就会「有钱没处花」。
4. **叙事密度集中在开场**：INTRO 一段文本承载了全部世界观，中途缺少节奏性的「轮回手表播报」。
