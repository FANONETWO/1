# 轮回回廊 · 项目简介

> **单机回合制 CRPG** ｜ **无限流**题材 ｜ Godot 4.7.2 · GDScript · 2D 像素
> 当前切片：第一个副本 **「惊变公寓」**（丧尸公寓 · D 级 · 存活率 12%）

---

## 一句话

你被「主神」丢进轮回。第一场影片是深夜的公寓楼：
走廊里有东西在拖行，楼上有人一直没下班，而出口的消防门锁着。

活下来，或者成为这栋楼的又一层记忆。

---

## 这个切片里有什么

| 系统 | 说明 |
|---|---|
| **D10 骰池检定** | 掷「属性 + 技能」枚 D10，每枚 ≥8 计 1 成功，掷出 10 可追加一骰；成功数 ≥ 难度即通过。0 级技能有真实惩罚（心智系直接无法判定） |
| **回合制潜行探索** | 你行动一次 → **每个敌人各走一步**。敌人有视野锥与朝向：站在它背后是突袭（抢先手），走进锥里就是它先手 |
| **战场迷雾 + 已探索记忆** | 只看得清 6 格内、且没有被墙挡住的地方；**走过的房间会留下暗色轮廓**，回头不至于摸黑 |
| **噪音驱动的尸潮** | 走动、翻柜子、开枪都会积噪音，到 **6 / 10 / 14** 分别招来逐尸 / 爬行者 / 尸群。安静几回合会自己衰减 |
| **AP 制战斗** | 每回合 6 行动点：移动 1 格 1 点、攻击 3 点、防御 2 点（+2 防御）；带火纹式战斗特写与伤害飘字 |
| **血统系统** | 十系 × D→S 五级 × 四层节点；排斥度 / 协同度 / 融合技 / 基因崩溃，以及高排斥下的**「血脉失控」** |
| **九属性 × 战棋出口** | 力量→近战伤害、敏捷→移动力、耐力→生命、感知→暴击、操控→威慑、沉着→首击减伤…… 每条属性都能在战棋里兑现，没有废属性 |
| **12 个箱庭地图** | RE2 式单房间箱庭，走到门格换房间（**不换场景**），因此战斗、掉落、尸体状态跨房间保留 |
| **3 条任务 + 2 个 NPC** | 活着离开 / 老邻居 / 清道夫；陈叔，以及一位**不可靠叙述者**阿贵 |
| **程序化音画** | 地形与音效全部代码生成（9 种 tile、19 音效 + 3 首 BGM），不依赖任何外部素材 |

## 怎么跑起来

```powershell
$godot = "你的 Godot 4.7.x 可执行文件路径"
Set-Location <项目目录>

# ① 首次：注册 class_name（不跑会报一堆 Identifier not found）
& $godot --headless --path . --editor --quit

# ② 玩
& $godot --path .          # 主菜单 → 新的开始 → 建卡 → 主神空间 → 进入副本

# ③ 跑全部 31 项测试
pwsh -File tools/run_tests.ps1
```

## 工程现状

- **31 项自动化测试全绿**（单测 10 + 场景/流程 21），每个测试带**墙钟时间戳 + 硬上限**看门狗，
  卡住的会被标 `TIMEOUT` 而不是把整批回归拖死（`tools/run_tests.ps1`）
- **分层目录**：`data/`（数据表）· `rules/`（规则逻辑）· `world/`（地图与世界）·
  `battle/`（战斗表现）· `ui/`（界面与入口）· `scenarios/`（副本）· `legacy/`（退休归档）
- **结构化操作日志** `DebugLog`：可 grep、可断言、可落盘 —— 排查不靠截图猜
- **已知缺口**：剧情阶段 2「车库」尚未实现；五界目前只做了第一界
