## 二、重大分歧清单（照着旧文档写代码一定会错）

### 1. 战斗判定：百分比 → **D10 骰池**
- **旧文档**：火纹式「命中 % / 暴击 / 闪避」
- **现实现**：掷「属性 + 技能」枚 D10，**每枚 ≥8 记 1 成功**，掷出 10 可追加一骰；
  成功数 ≥ DC 即成功（战斗内为对抗判定）
- **受影响**：`战斗与美术规格.md`、`游戏策划案.md`

### 2. 探索模式：实时 → **回合制**
- **旧文档**：「探索模式（实时）」
- **现实现**：**玩家行动一次 → 每个敌人各走一步**。只有回合制才能让"敌人什么时候转身"
  可观察、可计算，潜行才有策略
- **受影响**：`探索与战斗融合方案.md`

### 3. 地图形态：一张整层大图 → **12 个独立箱庭**
- **旧文档**：`20×12` 整层大图，RE2 式环形动线
- **现实现**：**12 个单房间级箱庭**（`9~20 × 4~7`），**走到门格才切换房间**；
  数据驱动（`rooms.gd`），不换 `.tscn`，因此战斗 overlay 与敌人/掉落状态可跨房间保留
- **受影响**：`地图设计方案.md`、`剧本大纲_惊变公寓.md`（第 260 行）

### 4. 美术生产：AI 生图 → **程序化生成 + 免费素材**
- **旧文档**：Leonardo / Pollinations / img2img 流水线
- **现实现**：
  - tile → `tools/pixelart/gen_tiles.py`（9 种，平铺无缝）
  - 装饰 → `tools/pixelart/gen_deco.py`（8 种）
  - 战斗立绘 → FE-Repo 免费素材（**授权见 `assets/CREDITS.md`，`{IS}` 不可发布**）
- **受影响**：`素材生成方案.md`、`图生图战斗立绘流程.md`、`立绘美术规范.md`

### 5. 建卡点数：27 → **30**，且是**阶梯价**
- **现实现**：`ui/char_creation.gd`，购点 30 / 技能 20；
  阶梯价导致**会剩下买不起任何一级的零头** → 已修成"无可分配即可确认"
- **受影响**：`游戏策划案.md`

### 6. 血统装配：**节点必须放进 `picked`**
- **旧文档**：只说了 `owned` 形如 `[{"id": "vampire", "rank": "D"}]`
- **实测**：只给 `rank` 无法解锁任何节点，所有加成为 0
- **正确写法**：`{"id": "werewolf", "rank": "B", "picked": ["steel_claw", "blood_moon"]}`
- **受影响**：`血统模块设计方案.md`（已补充）

### 7. 测试数量：6 / 11 / 15 → **26 项**
- 多份老文档里的测试数字都过期了。**以 `docs/项目说明.md` 的清单为准。**
