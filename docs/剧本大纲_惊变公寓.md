# 《轮回回廊 · 惊变公寓》剧本大纲 v1.0

> **一句话**：把「事件」从「点一下看一段字」升级为**有检定、有分支、有代价、有回报**的 CRPG 场景。
> **前置**：本大纲针对**世界 1 · 惊变公寓**（当前唯一有内容的世界）。五界框架沿用 [五界设计方案](轮回回廊_五界设计方案.md)。

---

## 一、体检报告：现行事件系统的五个病

| # | 病 | 现状证据 | 玩家感受 |
|---|---|---|---|
| 1 | **DC 与骰池不匹配** | 检定 `dc` 默认 **4**，而「操控+交际」骰池只有 **3 枚**（期望成功 0.9） | 「我点什么都是失败」 |
| 2 | **惩罚不透明** | 血统排斥在界面上显示为「**附加 −1**」 | 「骰子坏了？」 |
| 3 | **事件同质化** | 5 个调查点都是「看一眼 → 给一句话」 | 没有抉择，只有点击 |
| 4 | **系统脱节** | 血统 / 意志 / 派生值 / 噪音 / 感染**全都不进事件** | 建卡毫无意义 |
| 5 | **内容量不足** | 2 NPC + 5 调查点 ≈ 8 分钟 | 撑不起 30 分钟 |

**结论**：不是「文本需要润色」，而是**事件与规则内核之间没有接口**。下面全部重做。

## 二、检定设计规范（先解决病 1、2）

### 2.1 骰池预期表（D10，≥8 计成功，p = 0.3）

| 玩家类型 | 典型骰池 | DC 2 | DC 3 | DC 4 | DC 5 |
|---|---|---|---|---|---|
| **主攻**（属性 4 + 技能 3） | 7 | 96% | 87% | 71% | 50% |
| **熟练**（属性 3 + 技能 2） | 5 | 88% | 71% | 50% | 30% |
| **业余**（属性 2 + 技能 1） | 3 | 66% | 42% | 22% | 10% |
| **生手**（属性 1 + 技能 0） | 1 | 30% | 10% | 3% | 1% |

> 建卡 30 点 ÷ 9 属性 ≈ 3.3 均值 → 玩家**不可能样样精通**。所以每个事件必须标注**推荐属性**，让玩家用「我擅长的方式」解决。

### 2.2 DC 分配铁律

| 用途 | DC | 说明 |
|---|---|---|
| **主线必经** | **≤ 3**，且**至少 2 种解法** | 失败也能前进，只是代价更高 |
| 支线 / 加分 | 3 ~ 4 | 拿额外资源或线索 |
| 极限挑战 | 5 | 给稀有奖励，**允许失败** |
| 环境/氛围 | 2 | 基本必过，用来「确认玩家看到了」 |

**核心原则：失败前进（Fail Forward）** —— 检定失败**绝不卡关**，只改变代价与后续事件。

### 2.3 界面必须说人话

| 现在 | 改成 |
|---|---|
| `附加 -1` | `血脉干扰 −1`（血统排斥）/ `基因锁 +1` |
| `掷 3 枚，骰面成功 0` | `操控 1 + 交际 2 = 3 枚骰 ｜ 预期成功 0.9 ｜ 难度 4 → **成功率约 22%**` |
| 事后才报结果 | **事前显示成功率和失败代价**（让玩家决定是否投入意志力） |

> 这一条是最廉价的体验提升：**把骰池的黑箱打开**。

## 三、叙事骨架（三幕 = 三阶段）

```
第一幕 · 惊醒（一层）      你在一层醒来，楼里已经不正常了
     转折：拿到钥匙 → 广播警告「一层已封锁」→ 必须往下走
第二幕 · 下坠（地下车库）   黑暗、尸犬、以及「官方早就知道」的证据
     转折：血清 + 配电箱 → 得知大厅被「老周」占据
第三幕 · 破晓（大厅/消防通道） 与变异的前保安队长了结，选择怎么出去
     转折：消防通道的血字「别开门」→ 三结局
```

**情绪曲线**：困惑 → 恐惧 → 愤怒 → 抉择

## 四、角色表

| 角色 | 身份 | 功能 | 出场 |
|---|---|---|---|
| **陈叔** | 402 独居老人 | 提供**尸王弱点**（必须有他才能「弱点击破」）；说服他开门是道德题 | 阶段 1 |
| **疯子阿贵** | 幸存者，精神不稳 | 提供**噪音机制**情报，但**一半是假的**（洞察可识破） | 阶段 1 |
| **值班员小林** | 被困在车库值班室 | 远程无线电指引 → 阶段 2 的导航与情报源 | 阶段 2 |
| **4 楼母女** | 母亲 + 小女孩 | **道德抉择**：救她们会拖慢撤离并推高噪音 | 阶段 2 |
| **老周**（尸王） | 前保安队长 | **有名字的 Boss**。他封锁了大厅是为了「不让东西出去」——他不是纯反派 | 阶段 3 |

> 关键改动：**Boss 有名字、有动机**。BG3 的敌人之所以立得住，是因为你在打之前就知道他是谁。

## 五、事件清单（全部重做）

**每个事件的统一格式**：
```
【事件名】位置
  触发 / 检定（属性+技能，DC）/ 成功 / 失败（不卡关）/ 线索 / 系统交互
```

### 阶段 1 · 一层（8–10 分钟，8 个事件）

**【1-1】储物间柜子**　(2,1)
- 无检定。拿到**钢管**（`bat`）+ **绷带**
- 系统：破柜门**噪音 +2**

**【1-2】值班室药柜**　(8,2)　★多解
- **开锁**：敏捷+盗窃 DC 3 ／ **撬锁**：力量+运动 DC 3（**噪音 +4**）
- 成功：**安全出口钥匙** + 降压药
- 失败：锁芯崩坏 → 只能撬（**噪音 +4**，并触发一次遭遇）
- 线索①：柜底旧报纸下的值班表

**【1-3】值班室桌面**　(10,3)
- 感知+调查 **DC 2**
- 成功：**物业日志**（老周最后一天值班记录）→ 线索③
- 失败：字迹被血浸透，只看出「9.13」

**【1-4】空房床垫**　(15,1)
- 感知+调查 **DC 3**
- 成功：床下行李箱 → **防刺背心** + 线索②
- 失败：什么都找不到（**可重复尝试，但每次噪音 +1**）

**【1-5】楼梯间**　(16,10)
- 剧情：楼梯被卷帘门封死 → 提示「必须找别的路」
- 系统：**解锁阶段 2 的入口**（电梯井）

**【1-6】陈叔对话**　(6,2)　★道德题
- 三层对话树：**敲门**（噪音 +2）→ 隔门对话 → **说服**（风度+说服 DC 3 / 或**智力+共情 DC 2** 说出降压药的事）
- 成功：陈叔开门，给出**尸王弱点**（打头/打断左臂）+ 线索④
- 失败：他不信你。**可以之后再回来**（拿到降压药后自动成功）

**【1-7】阿贵对话**　(15,8)　★识破
- 他告诉你「丧尸靠声音找人」（**真的**）+「车库里有 20 只」（**假的**）
- 感知+洞察 **DC 3** → 识破 → **获得准确情报**（车库实际 4 只）
- 失败：你信了他 → 阶段 2 会被误导（多绕路，噪音累积）

**【1-8】402 的门**　(6,1)　★代价抉择
- 可**强行破门**（力量+运动 DC 4，**噪音 +6**）→ 拿到**线索⑤**（陈叔藏的东西：一张全楼住户名单）
- 注意：破门后**陈叔的对话线关闭**（他不原谅你）→ **拿不到弱点**
- 这是全剧第一个真正的**取舍**：情报 vs 战力

### 阶段 2 · 地下车库（10–12 分钟，8 个事件）

**【2-1】配电箱**　★强抉择
- 拉闸：**噪音 +5**，但**全图视野 4 → 8 格**
- 不拉：视野永远是 4 格，潜行极难，但安静
- 系统：直接影响整个阶段的打法

**【2-2】冰柜血清**　
- 力量+运动 **DC 3** 撬开
- 成功：**血清**（清除全部感染度，一次性）
- 失败：手滑，**感染度 +1**

**【2-3】车辆掩体搜刮** ×3
- 感知+调查 **DC 2**
- 成功：弹药 / 急救包 / 燃油（阶段 3 有用）

**【2-4】尸犬追踪**　强制遭遇
- 无法避免。**用「噪音」决定遭遇规模**（低噪音 = 1 只，高噪音 = 3 只）
- 这是把噪音机制**变成战斗变量**的地方

**【2-5】小林无线电**
- 智力+科技 **DC 3** → 建立通讯，获得**大厅地图情报**（尸王位置 + 弱点提示）
- 失败：信号断断续续，情报不全（少一个提示）

**【2-6】4 楼母女**　★道德题
- 通过电梯井喊话：风度+说服 **DC 4**
- 成功：她们**原地等待**，撤离时自动脱险 → 完美结局 +1 条件
- 失败：她们乱跑 → **噪音持续 +2/回合**，并可能引来尸潮
- **也可以直接不理会**（无惩罚，但拿不到完美结局）

**【2-7】尸体堆**　★属性出口
- 决心+坚毅 **DC 3**（**忍受翻找**）
- 成功：线索⑥（车库封条：**官方在 9.13 之前就封锁过这里**）
- 失败：生理性呕吐，**意志 −1**（这条专门给「决心」属性一个舞台）

**【2-8】车钥匙**　★可选捷径
- 敏捷+盗窃 **DC 3**
- 成功：拿到皮卡钥匙 → 阶段 3 可以**直接冲过前厅**（跳过 1 个战斗遭遇）

### 阶段 3 · 大厅与消防通道（10–12 分钟，6 个事件）

**【3-1】消防门**
- 需钥匙（阶段 1 拿到）。无检定，但**开门噪音 +3**

**【3-2】老周（尸王）**　★Boss 战前对话
- **战前独白**：他还在做保安的动作，反复说「不能出去」
- **若有陈叔情报** → 战斗中获得「弱点击破」（+2 成功，每场 3 次）
- **若有小林情报** → 得知他左臂是弱点（防御 −1）
- **血统高排斥** → 此战中**失控风险翻倍**（剧情解释：血脉被尸气刺激）

**【3-3】尸潮倒计时**
- 噪音 ≥14 触发：**3 回合内必须结束战斗或撤离**，否则无限刷丧尸
- 这是把「噪音」推到高潮的设计

**【3-4】消防通道血字**　线索⑦
- 无检定。墙上有人用血写：「**别开门**」
- **反转**：安全出口外面**未必安全** → 影响最终选择

**【3-5】撤离抉择**　★三结局分岐
- **开门撤离**：常规结局（若线索 <3 → 惊险撤离）
- **从消防梯绕行**：需要敏捷+运动 DC 4，成功 → 完美撤离（**但母女若在等待需回头接**）
- **留下封门**：牺牲自己保住外面的世界 → **隐藏结局「守门人」**（需要线索 ≥3 才解锁）

**【3-6】结算**
- 按 `钥匙 + 支线完成数 + 线索数 + 是否救母女` 计算评价

## 六、线索链（7 条 → 一条真相）

| # | 线索 | 来源 | 拼出的信息 |
|---|---|---|---|
| ① | 值班表（血手印） | 1-2 | 疫情起点是 **9.13 夜班** |
| ② | 行李箱里的药 | 1-4 | 有人**早就知道自己会变异** |
| ③ | 物业日志 | 1-3 | 老周最后一天在**封大厅** |
| ④ | 陈叔的名单 | 1-6 | 全楼住户，**少了一个人** |
| ⑤ | 402 的藏物 | 1-8 | 陈叔**在保护某个人** |
| ⑥ | 车库封条 | 2-7 | **官方 9.13 之前就封锁过这里** |
| ⑦ | 消防通道血字 | 3-4 | 「别开门」——**外面在等他们出去** |

**真相**：这不是意外泄漏，而是**一次有预谋的「收容」**。老周封住大厅不是疯了，是**在执行封锁令**。
收集 **≥3 条** → 解锁隐藏结局分支与主神空间的额外情报。

## 七、结局与评价

| 结局 | 条件 | 奖励 |
|---|---|---|
| **完美撤离** | 钥匙 + 支线 ≥2 + 线索 ≥3 + 救下母女 | 满额奖励 + 隐藏情报 |
| **惊险撤离** | 拿到钥匙，其余不足 | 基础奖励 |
| **守门人**（隐藏） | 线索 ≥3 且**选择留下封门** | 特殊评价 + 主神空间特殊兑换 |
| **陨落** | 生命归零 | 强制结算 + 惩罚 |

## 八、与现有系统的接口（解决病 4）

| 系统 | 在事件中的用法 |
|---|---|
| **九属性** | 每个事件标注推荐属性，且**每个属性至少有 1 个专属高光事件**（决心→2-7，风度→1-6/2-6，感知→1-7，操控→阿贵识破，智力→2-5，敏捷→1-2/2-8，力量→1-8/2-2，耐力→感染抗性，沉着→尸潮中的稳定） |
| **意志力** | 检定 +1 成功（已有）；**新增**：尸潮倒计时中花费 1 点**延长 1 回合** |
| **血统** | 排斥惩罚显示为「血脉干扰 −N」；高排斥在 Boss 战中**失控风险翻倍**；协同度高则**解锁特殊对话选项** |
| **派生值** | **战术点（智力/2）→ 每场可用「看穿弱点」次数**（直接进事件，让智力不再是废属性） |
| **噪音** | 成为**检定的隐性代价**（撬锁/破门/开枪都会推高），并决定遭遇规模与尸潮 |
| **感染** | 事件中受伤/失败会累积，>3 时**检定 −1**（形成恶性循环，逼玩家找血清） |
| **基因锁** | 濒死触发时**在事件中也有一次「爆种」机会**（如强行破门 DC 4 → 自动成功） |

## 九、实现优先级

### P0 · 立刻（半天）
1. **DC 重标定**：现有事件 DC 4 → 2~3，必经事件加第二解法
2. **检定界面改造**：显示「骰池构成 + 预期成功 + 成功率 + 失败代价」
3. **惩罚文案**：`附加 −1` → `血脉干扰 −1`

### P1 · 短期（1–2 天）
4. **多解路径**：1-2 / 1-6 / 2-1 / 2-6 落地
5. **线索面板**：7 条线索的收集与查看
6. **Fail Forward**：所有检定失败都有替代前进路径

### P2 · 中期
7. 新增 NPC（小林 / 母女）与对应对话树
8. 阶段 2 / 3 地图（车库 20×14、大厅 16×12）
9. Boss 战前对话与弱点击破接线
