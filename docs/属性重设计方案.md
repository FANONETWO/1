# 属性重设计方案（对齐现行策划案）

> 结论先行：**9 属性全部保留**（它们是骰池内核与规则书蓝本），但要让**每一项都拥有一个战棋机制出口**
> —— 现状是 3 项半有用、5 项半作废，所有 build 都往敏捷堆。

---

## 一、诊断：为什么必须重做

现状（`data/attrs.gd` + `rules/character.gd`）：

| 属性 | 现有系统作用 | 战棋里有出口？ |
|---|---|---|
| 力量 STR | 近战攻击 DP | ✓ |
| 敏捷 DEX | 防御 + 远程 DP + 先攻 | ✓✓✓ **过强** |
| 耐力 END | 生命 = 4×耐力 | ✓ |
| 智力 INT | 心智检定 | ✗ |
| 感知 PER | 调查/察觉检定 | ✗ |
| 决心 RES | 意志力上限 | ✗（意志力战斗内无用途，策划案自认） |
| 风度 PRE | 社交第一印象 | ✗ |
| 操控 MAN | 交际/胁迫/掩饰 | ✗ |
| 沉着 COM | 意志力上限 + 先攻 | △ 半个 |

**三个致命后果**：

1. **建卡时无人投 5 项属性** —— 投了就等于把 27 点之一丢进水里；战棋角色的配点被压缩成「力量/敏捷/耐力」三选。
2. **敏捷独大** —— 防御、远程、先攻全吃敏捷，最优解永远是堆敏捷。
3. **基因锁设计被架空** —— 策划案里基因锁维持轮数 = `min(耐力, 决心, 沉着)`，而后两者在战斗中没价值（爆种时才发现自己没投）。

对齐策划案的三条主线（**火纹式战棋 / CRPG 叙事 / 五界成长**），属性必须满足：
**① 每项都有战棋出口 ② 每项都有叙事出口 ③ 标度能跨世界成长。**

---

## 二、新设计：三轴九属性，一属性一机制

### 2.1 肉体轴（前线：扛、打、跑）

| 属性 | 战棋机制（新增/明确） | 叙事出口 |
|---|---|---|
| **力量** STR | 近战伤害 = 武器 + 力量/2；破门、推撞、负重 | 物理威慑、蛮力解谜 |
| **敏捷** DEX | **移动力 = 3 + 敏捷/2**；回避；先攻 | 潜行、脱逃、扒窃 |
| **耐力** END | 生命 = 8 + 4×耐力；抗毒/抗感染 | 忍耐、跋涉、抗病 |

### 2.2 心智轴（爆发与信息）

| 属性 | 战棋机制 | 叙事出口 |
|---|---|---|
| **智力** INT | **战术点 = 智力/2**（每场战斗可「看穿弱点」：让一次攻击 +2 成功） | 学识、破解、医疗、分析 |
| **感知** PER | **暴击率 = 5%×感知**（暴击伤害 ×2）；射程与视野、识破伏击 | 洞察、辨谎、搜索 |
| **决心** RES | **意志力池 = 2×决心**（战斗资源，见第四节） | 抗压、意志对抗、抵御精神攻击 |

### 2.3 社交轴（团队与压制）

| 属性 | 战棋机制 | 叙事出口 |
|---|---|---|
| **风度** PRE | **指挥光环**：风度/2 格内的队友命中 +1 | 说服、领导、安抚 |
| **操控** MAN | **威慑**：相邻敌人命中 −1；反击判定 +操控/3 | 欺骗、威吓、诱导 |
| **沉着** COM | **先攻 = 敏捷 + 沉着**；**处变不惊**：每回合首次受击减伤 沉着/3 | 冷静、谈判、压力应对 |

> 九项全部落地，且都是火纹玩家一眼就懂的机制（暴击 / 命中光环 / 威慑 / 先攻 / 移动力）。

---

## 三、火纹式战斗面板（玩家直接看到的数值）

战斗 UI 应直接展示这些派生值，而不是让玩家心算骰池：

| 面板数值 | 公式 | 备注 |
|---|---|---|
| 生命 HP | `8 + 4×耐力` | 原为 `4×耐力` |
| 意志 WILL | `2×决心` | 原为 `决心+沉着` |
| 命中 HIT | `60 + 技能等级×5 + 主属性×2 − 敌回避` | 已有公式，明确「主属性」=近战力量 / 远程感知 |
| 伤害 DMG | `武器伤害 + 力量/2`（远程用感知/2） | 让感知兼管远程 |
| 防御 DEF | `敏捷 + 躲藏/2 + 护甲 + 地形` | 已有 |
| 暴击 CRIT | `5% × 感知` | **新增** |
| 移动 MOV | `3 + 敏捷/2` | **新增**（原来玩家移动力无来源） |
| 先攻 INIT | `敏捷 + 沉着` | 已有 |
| 战术点 TAC | `智力/2` 次/场 | **新增** |
| 指挥光环 | `风度/2` 格 | **新增** |
| 威慑 | 相邻敌人 −1 命中 | **新增** |
| 首击减伤 | `沉着/3` | **新增** |

## 四、意志力：激活废属性的关键（策划案 M1 待实现项）

**上限 = 2 × 决心**（原为 决心+沉着，改为决心独享，让「决心」有明确身份）。

**战斗内，每回合限 1 次**，投入 1 点意志力选择：

| 用法 | 效果 | 定位 |
|---|---|---|
| **专注** | 本次攻击 +1 成功 | 攻坚/Boss |
| **固守** | 本回合防御 +1 | 扛线 |
| **闪避** | 抵消一次命中 | 保命 |

**非战斗**：推动一次检定 +1 成功（剧情关键抉择）。

> 这一条直接把「决心」从废属性变成**战棋的资源属性**，也让基因锁的维持成本有了载体。

---

## 五、标度与成长（支撑五界跨度）

原设计 1–6 封顶，撑不起「丧尸世界 → 仙侠世界」的跨度。新标度：

| 区间 | 称号 | 获得途径 |
|---|---|---|
| 1 | 孱弱 | 建卡下限 |
| 2 | 常人 | 建卡默认 |
| 3–4 | 老练 | 建卡主力区间 |
| 5 | 人类极限 | **建卡上限** |
| 6–7 | 超凡 | 基因锁一阶 / 主神兑换 |
| 8–10 | 传奇 | 基因锁二阶（生理 +6）/ 高阶兑换 |
| 11+ | 半神 | 仙侠/终局世界 |

**附加成功**门槛保持 `≥6` 给 1 个、每 +5 再 +1（与规则书一致），因此**突破 6 是质变点**：
建卡封顶 5 = 「你还只是个人」，基因锁/兑换才能越界 —— 这与无限流的成长感完全契合。

**建卡池调整**：27 → **30 点**（原 27 点无法把两项堆到 5 再补其他；30 点让「专精两项 + 平均其他」成为可行 build）。

## 六、出身模板（对齐 CRPG 道途）

保留现有「天赋 5 选 1」，但每个天赋补上**推荐配点**与**独有被动**，建卡界面直接显示，
让玩家选出身时就知道自己要打什么流派：

| 出身 | 推荐配点 | 独有被动 |
|---|---|---|
| 街头搏击手 | 力量 4 / 敏捷 3 / 耐力 3 | 肉搏 +1、白刃 +1、近战伤害 +1 |
| 退役军医 | 感知 4 / 智力 3 / 决心 3 | 医学 +1、枪械 +1、战术点 +1 |
| 夜班保安 | 耐力 4 / 决心 3 / 敏捷 2 | 求生 +1、生命 +4、首击减伤 +1 |
| 落魄推销员 | 风度 4 / 操控 3 / 沉着 3 | 交际 +1、胁迫 +1、指挥光环 +1 格 |
| 老练黑客 | 智力 4 / 沉着 3 / 感知 2 | 调查 +1、神秘学 +1、战术点 +1 |
| 街头混混 | 操控 4 / 敏捷 3 / 力量 2 | 掩饰 +1、躲藏 +1、威慑范围 +1 |

## 七、迁移路径（不动底层，可分批落地）

| 阶段 | 内容 | 影响面 |
|---|---|---|
| **P0** | `character.gd` 新增派生：移动力、暴击率、战术点、光环、威慑、首击减伤；建卡 UI 显示推荐配点 | 低（只加不改） |
| **P1** | **意志力战斗内投入**（专注/固守/闪避）：战斗场景加三个按钮 + 每回合限 1 次 | 中 |
| **P2** | 暴击落地（伤害 ×2 + 演出）、指挥光环与威慑的气场显示 | 中 |
| **P3** | 建卡池 27→30、标度扩张到 11+、兑换价格对齐（属性 ×100 分 / 技能 3XP） | 中高（动建卡与存档） |
| **P4** | 出身模板补全被动；对话检定 UI 标注「[感知]」「[风度]」标签 | 低 |

**兼容性**：现有 `Attrs.ALL` / `NAMES` / 技能映射**全部不变**，存档 v2 结构不变（属性仍是 `attrs` 字典）；
上述新增全是**派生函数**与**战斗机制**，因此不破坏 11 项回归测试。

## 八、与策划案的对应关系（为什么这样改）

| 策划案主线 | 本方案如何服务 |
|---|---|
| **火纹式战棋** | 直接产出火纹核心机制：暴击、命中光环、威慑、先攻、移动力、战术点 |
| **CRPG（BG3/开拓者）** | 9 属性 × 12 技能的检定体系保留；每属性都有对话出口（见第二、三节） |
| **五界自由进入与成长** | 标度 1–11+ 支撑「丧尸 → 仙侠」的跨度；建卡封顶 5 保住「凡人感」 |
| **基因锁** | 决心=意志力池、维持轮数 = min(耐力,决心,沉着) 三个属性终于都有战斗价值 |
| **主神空间养成** | 兑换价格与标度扩张对齐，中后期不再「有钱没处花」 |

## 九、验收清单（实施后必须全绿）

1. 建卡时 9 项属性的每一项，UI 都写明「战术作用 + 叙事作用」。
2. 战斗面板显示 HP / 意志 / 命中 / 伤害 / 防御 / 暴击 / 移动 / 先攻，且与属性实时联动。
3. 意志力可在战斗内投入，每回合限 1 次，三种用法均生效。
4. 属性从 5 → 6 时，附加成功从 0 变 1（质变点可见）。
5. 11 项自动化测试保持全绿；新增「派生数值」单测。
