## 一、战斗系统重构

### 1.1 网格与视口（像素规格联动）

| 项 | 规格 | 理由 |
|---|---|---|
| 基准视口 | **320 × 180** | 1280×720 ÷ 4 = 整数倍缩放，像素不糊 |
| 放大 | 整数 ×4（`canvas_items` + 最近邻） | 像素完美 |
| Tile | **16 × 16** | 经典像素尺寸，素材最丰富 |
| 战场视野 | **20 × 11 格** | 320/16 = 20、180/16 = 11.25 |
| 角色 sprite | 16 × 24（站立超出格子，火纹式「大头小身」） | 视觉辨识度 |
| 网格类型 | **方格俯视**，4 方向移动（上下左右） | 火纹原作 |

### 1.2 单位数据模型

一个战斗单位 = 角色 + 装备 + 位置 + 状态。

| 字段 | 来源 | 说明 |
|---|---|---|
| HP | 耐力 × 4（天赋 +4） | 沿用 |
| 力量/敏捷/感知… | 角色的 9 属性 | 沿用，作为战斗数值的输入 |
| **命中 Hit** | 60 + 主技能等级 × 5 + 敏捷 × 2 | 基础命中率 |
| **回避 Avoid** | 敏捷 × 3 + 躲藏 × 3 + 地形回避 | 受地形与状态修正 |
| **暴击 Crit** | 感知 × 2 + 武器暴击 − 敌方沉着 | 暴击 ×3 伤害 |
| **攻速 Speed** | 敏捷 − max(0, 武器重量 − 力量) | 差值 ≥4 触发**追击** |
| **防御 Def** | 护甲 + 地形防御 + 防御姿态 2 | 减伤 |
| **移动力 Move** | 3 + 敏捷 ÷ 2（上限 6） | 火纹式移动范围 |
| **射程 Range** | 近战 1 · 长兵 2 · 远程 1–3（枪械 4） | 显示攻击范围 |

### 1.3 判定公式（火纹百分比）

```
命中率 = clamp(武器命中 + 技能等级×5 + 属性修正 − 敌方回避 − 地形回避, 5, 95)
       掷 1d100 ≤ 命中率 → 命中
暴击率 = clamp(感知×2 + 武器暴击 − 敌方沉着, 0, 80)
       命中后掷 1d100 ≤ 暴击率 → 伤害 ×3
追击   = 攻速 ≥ 敌方攻速 + 4 时，同一次行动再攻击一次（火纹经典）
伤害   = max(0, 力量(或智力) + 武器威力 + 技能加成 − 敌方防御)
       暴击时 ×3；武器相克再 ±1
```

> 设计说明：保留「骰池成功数」的味道可通过**技能等级**进入公式（技能越高命中越稳），但战斗不再掷多枚骰子——节奏更快、可读性更强，符合火纹手感。

### 1.4 武器相克三角

| 类型 | 代表武器 | 克制 | 被克 | 效果 |
|---|---|---|---|---|
| 白刃 | 开山刀 · 飞剑 · 魔法刃 | 重击 | 长兵 | 命中 +15、伤害 +1 |
| 重击 | 钢管 · 斧 · 拳套 · 巨锤 | 长兵 | 白刃 | 命中 +15、伤害 +1 |
| 长兵 | 长枪 · 法杖 · 撬棍 | 白刃 | 重击 | 命中 +15、伤害 +1 |
| 远程 | 手枪 · 猎枪 · 符箓 · 法术 | — | — | 不受三角影响，但**有弹药/耐久限制** |

**世界差异化**：仙侠的「剑/法/符」、科幻的「实弹/能量/EMP」、魔幻的「火/冰/雷」都映射到同一三角，玩家只需学一次相克关系（`worlds/w*/world.gd` 用 `weapon_type` 覆盖显示名）。

### 1.5 地形表

| 地形 | 回避 | 防御 | 移动消耗 | 备注 |
|---|---|---|---|---|
| 平地 / 走廊 | 0 | 0 | 1 | — |
| 森林 / 书架 | +15 | 0 | 2 | 火纹经典回避位 |
| 废墟 / 掩体 | +10 | +1 | 2 | 可拾荒（世界 5） |
| 高地 / 天台 | +5 | 0 | 2 | 攻击时命中 +10 |
| 门 / 楼梯 | 0 | 0 | 1 | 可通往下一阶段 |
| 火海 / 辐射区 | −10 | 0 | 1 | 每回合受 2 点环境伤害 |
| 墙 / 障碍 | — | — | ∞ | 不可通行（可被破坏） |

### 1.6 回合流程

```
玩家阶段 ─▶ 每个我方单位：移动（≤移动力）→ 行动（攻击 / 道具 / 特殊 / 待机）
         └─▶ 全部行动完毕后进入敌方阶段
敌方阶段 ─▶ AI 单位依次按同一规则行动（贪心接近 + 优先打残血/低回避）
         └─▶ 回合数 +1，回到玩家阶段
胜负     ─▶ 敌方全灭 或 达成阶段目标（Boss 击杀 / 撤离 / 倒计时结束）
```

**关键规则**

- **一人一次**：每单位每回合 1 次移动 + 1 次行动（取代原 6 AP 池）。
- **反击**：防守方存活且攻击者在自身射程内 → 反击一次（不受「一人一次」限制）。
- **死亡**：我方单位 HP 归零即阵亡；**玩家**首次归零仍触发「绝境爆种」，其余单位永久退场（本场战斗）。
- **单位移动范围/攻击范围高亮**：蓝色可移动格、红色可攻击格、黄色路径预览——火纹的招牌 UI，必须做。

### 1.7 D10 骰池的新定位

战斗改用百分比后，骰池**不废弃**，转为**非战斗判定的唯一体系**：

| 场景 | 判定方式 |
|---|---|
| 调查点 / 开锁 / 破译 | D10 骰池 vs DC（保留附加成功门控、0 级惩罚） |
| NPC 对话检定 | D10 骰池（安抚/逼问/谈判） |
| 世界机制的非战斗部分 | 骰池（如入侵终端、拆解废墟） |
| **战斗内** | **百分比命中/暴击/追击**（火纹） |

这样「探索像 TRPG、战斗像火纹」，两种手感各司其职。

## 二、队伍系统（三种形态全支持）

### 2.1 三种队伍形态

| 形态 | 来源 | 上限 | 特点 | 收益/代价 |
|---|---|---|---|---|
| **常驻队友** | 主神空间招募（人造人 500 分 / 随从 200 分 / 动物伙伴 200 分，还原 re25） | 队伍共 4 人 | 可养成、可配装、跨世界携带 | 花奖励点；分摊经验 |
| **独行** | 不招募，玩家单人出战 | 1 人 | 潜行/刺杀流，火纹的「孤狼」玩法 | **奖励点 +15%**、基因锁熟练度每场 +1 |
| **临时友军** | 副本内救下的 NPC（陈叔、幸存者、工程师） | 每界 1–2 人 | 该界专属，通关后解散 | 死亡影响结局评级（不删档） |

### 2.2 出战与操控

- 玩家**全控**我方全部单位（火纹传统，不做友军 AI，降低复杂度）。
- 出战编成界面：从已招募队友中选择上场（最多 4 人），世界卡片上标注「推荐人数」。
- 队友死亡：常驻队友在副本中阵亡 → 本场退场，副本结束后在主神空间以 50% 招募价复活（软惩罚，不做永久死亡）。

### 2.3 队友数据

```gdscript
{
  "id": "android_01", "name": "造人·壹号", "kind": "android",
  "attrs": {...}, "skills": {...}, "talent_id": "", "weapon": "bat", "armor": "",
  "level": 1, "xp": 0, "portrait": "res://assets/portraits/android_01.png"
}
```

复用现有 `Character` 结构（`to_dict/from_dict`），新增 `team` 数组存入存档。

## 三、五界机制在火纹体系下的重新映射

| 世界 | 机制 | 火纹化后的形态 |
|---|---|---|
| 惊变公寓 | 噪音与感染 | 开枪噪音 +3 → 每回合按噪音值**增援刷新**敌人（火纹的增援机制）；感染度 → 状态栏减益 |
| 剑影仙途 | 内息与功法 | 灵力池 → **战技资源**：消耗灵力放「剑诀」（必中/加伤）、「御气」（本回合回避 +30）、「吐纳」（回灵力，不可移动） |
| 零号协议 | 护盾与入侵 | 护盾值 → 先扣的临时 HP；**入侵 = 夺取地图上的炮塔/无人机单位**（火纹式「说得/操纵」） |
| 黑月学院 | 元素相克与咏唱 | 元素直接挂进相克三角；咏唱 = **蓄力一回合**（火纹的「必定命中/大伤害」蓄力技），被打断则失效 |
| 灰烬公路 | 辐射与耐久 | 辐射区 = 地形伤害 + 命中减益；**武器耐久 = 火纹原作机制**（每攻击一次 −1，归零损坏） |

> 巧合但好用：**武器耐久本来就是火纹的招牌**，废土世界的机制天然契合。

## 四、像素美术管线

### 4.1 规格

| 项 | 规格 |
|---|---|
| 视口 | 320 × 180，整数 ×4 放大到 1280×720 |
| Tile | 16 × 16 |
| 角色 | 16 × 24，站立 / 行走（4 帧）/ 攻击（3 帧）/ 受击（1 帧）/ 阵亡（1 帧） |
| 大单位（Boss） | 32 × 32 或 32 × 48，跨格显示 |
| 调色板 | **≤ 32 色**（每界一套 16 色主题盘：公寓冷蓝、仙侠青绿、科幻品红、魔幻紫金、废土土黄） |
| 特效 | 命中火花 / 暴击 / 治疗 / 元素，各 4–6 帧 |
| 字体 | 中文像素字体需内嵌（如「方舟像素」「Zpix 最像素」），字号 12/16 |

### 4.2 素材来源分层（AI + 免费素材）

**第一层 · AI 生成（角色、敌人、Boss、特效）**

| 工具 | 定位 | 价格 | 为什么选它 |
|---|---|---|---|
| **PixelLab**（主力） | 骨骼动画、4/8 向旋转、图块集、Aseprite 插件、API | 40 次免费试用；$12/月起 | 唯一把精灵当「可摆姿势的骨骼角色」处理，适合我们「一界 4–6 种敌人 × 5 界」的量产需求（[介绍](https://theresanaiforthat.com/ai/pixellab/)、[横向对比](https://app.cinevva.com/zh-CN/guides/ai-pixel-art-generators)） |
| **Retro Diffusion**（备选/长期） | Aseprite 扩展，本地生成，无点数 | 一次性：Lite $20 / 完整 $65 | 买断制最省钱、提示词与素材不出本机、输出归自己；需尚可的 GPU + Aseprite（[对比](https://app.cinevva.com/zh-CN/guides/ai-pixel-art-generators)） |
| Sprite-AI | 静态道具/图标 | 15 次免费，$8/月起 | 只做道具图标这类无动画素材，便宜（同上） |
| spritebrew（开源） | AI 精灵表生成 → 导出 Godot | 开源 | 若想全流程可控可自建（[GitHub](https://github.com/GAlbanese09/spritebrew)） |

**第二层 · 免费 CC0 素材（地形 tile、UI 框、图标）**

- **Kenney**（最全的 CC0 游戏素材库，tile/UI/音效）
- **Pixel Frog**、**Ansimuz**、**0x72** —— 高质量 CC0 像素包（参考同篇对比文章的免费替代清单）

**第三层 · 程序生成占位（先把系统跑通）**

- 我用代码生成纯色 tile + 简易单位色块（保留现有「零资源可运行」特性），保证**素材未就位时游戏仍可跑通与测试**。

**清理与编辑**：Aseprite（$19.99，行业标准）或免费 **LibreSprite / Piskel**。

### 4.3 质量验收（30 秒判断法）

1. **放大到 800%**：每个像素必须是完整单像素，无抗锯齿/模糊渐变。
2. **数颜色**：≤32 色（Aseprite 调色板查看）。
3. **看轮廓**：同一组精灵轮廓风格一致（统一描边或统一无描边）。
4. **看第二帧**：比例、颜色、细节不漂移，才算真动画。

### 4.4 目录与命名规范

```
assets/
  tiles/<world>/floor.png, wall.png, forest.png, ruins.png …    # 16×16，图集
  sprites/<world>/<unit>_idle.png / _walk.png / _attack.png …    # 16×24 帧序列或图集
  portraits/<unit>.png                                          # 48×48 对话立绘
  fx/<effect>.png                                               # 特效帧
  ui/panel_9patch.png, cursor.png, icons.png                     # UI 九宫格与图标
  fonts/pixel_zh.ttf
```

### 4.5 Godot 导入设置（像素不糊的关键）

- 项目级：`rendering/textures/canvas_textures/default_texture_filter = Nearest`
- 视口：`display/window/stretch/mode = canvas_items`、`scale_mode = integer`（**整数缩放**）
- 图集：关闭 mipmap、关闭 filter、`fix_alpha_border = true`
- 相机：位置取整（避免半像素抖动）

### 4.6 合规注意

- **Steam 要求披露 AI 生成素材**（商店页需声明），因此每份 AI 素材要记录工具、日期、提示词。
- 免费素材确认许可（**坚持只用 CC0**，避免署名与商用纠纷）。
- 建议维护 `assets/CREDITS.md`：来源 / 许可 / 生成工具 / 日期。
