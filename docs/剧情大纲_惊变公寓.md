# 《轮回回廊 · 惊变公寓》剧情大纲 v3

> **v3 修订说明**：v2 偏离了**无限流副本**的本质（写成了"循环 / 笔迹比对 / 存在主义"那类文艺片）。
> 副本不是文艺片，是**主神发布任务、你在限定条件下活下来**。
> 本版收敛为**标准恐怖片结构**，所有桥段都对应到具体影片。

---

## 零、类型定位与参考片单

**类型**：密室求生 · 丧尸 · 限时撤离（D 级新手本）

| 参考影片 | 借的东西 | 用在本副本哪里 |
|---|---|---|
| **《活死人黎明》** | 被困建筑 + 幸存者小团体 + 突围 | **全局结构**：起=被困，合=突围 |
| **《生化危机 2》** | 公寓/城市封锁 + 怪物分级 | 场景与敌人分级（尸王 = 追踪者位） |
| **《迷雾》** | 安全区其实是陷阱 + 冷峻结尾 | **"转"** 与结局基调 |
| **《寂静之地》** | 声音招怪 | **噪音机制**（开枪/破门/奔跑都会引怪） |
| **《釜山行》** | 密闭空间 + 救人要付代价 | 母女桥段 |
| **《28 天后》** | 军事封锁 + 封锁队撤离 | 转段的"封锁线"真相 |
| **《闪灵》** | 封闭空间里的人先疯 | 阿贵 |
| **《电锯惊魂》** | 抉择必有代价 | 事件设计的底层原则 |

> **纪律**：本副本不写"意义"，只写"怎么活"。每个桥段都要能回答「这参考了哪部片」。

## 一、主神任务（玩家进副本第一眼看到的）

```
┌─ 主神任务 ─────────────────────────────┐
│  副本：惊变公寓                          │
│  难度：D（新手）                         │
│  目标：天亮前离开公寓楼                   │
│  时限：06:00（手环倒计时）                │
│  失败：死亡 ／ 超时                       │
│  奖励：基础 1000 点                       │
│        ＋ 支线「老邻居」300               │
│        ＋ 支线「清道夫」500               │
│        ＋ 线索 5 条 × 50                  │
│  备注：本副本历史存活率 12%               │
└────────────────────────────────────────┘
```

**设计要点**：
- **主神全程不出面**，只给任务和结算 —— 冷，才是无限流的味道
- **"存活率 12%"** 是唯一的心理施压，不加任何旁白
- **支线明码标价**，让玩家主动计算"救不救人值不值"

## 二、故事内核

**一句话**：你在天亮前从一栋住满感染者的公寓楼里活着出去 —— 而主神只关心你有没有出去。

**真正的敌人不是丧尸，是"退路"**：
- 一层封死 → 只能往下
- 车库是病毒原点 → 待越久越危险
- 大厅被尸王占据 → 最后一道门
- **每一段都在切断你回头的能力**

**情绪曲线**：惊慌 → 稳住 → **绝境** → 拼命

## 三、起 · 承 · 转 · 合

| 段 | 标题 | 时长 | 恐怖片对应 | 这一段要干的事 |
|---|---|---|---|---|
| **起** | 醒来 | 8 min | 《活死人黎明》开场 | 建立威胁，拿到第一件武器，遇见幸存者 |
| **承** | 找路 | 12 min | 《寂静之地》 | 找钥匙、救人、搜物资，**噪音累积**，敌人升级 |
| **转** | 断路 | 8 min | **《迷雾》+《28 天后》** | **一层被封死，退路断绝**；车库揭示病毒原点 |
| **合** | 突围 | 10 min | 《活死人黎明》结尾 | 大厅 Boss 战 → 撤离 → 三结局 |

## 四、起 · 醒来（一层，8 分钟）

**开场**：你在一层楼梯间醒来。手环亮起，任务简报（见第一节）。走廊尽头有影子在动。

**节奏**（参考《活死人黎明》开场：先给声音，再给影子，最后给全貌）：

1. **听见**：有什么东西在拖行、在啃咬 —— 但你看不见它
2. **拿到第一件武器**：值班室门口靠着一根**钢管**（`bat`）。**空手开局**，这是第一口气
3. **第一次遭遇**：走廊的丧尸。**能躲就躲**（从背后绕过去），躲不掉才打
4. **第一个幸存者**：消防栓后面的**阿贵**，瘦得脱形，说胡话
5. **第一具尸体**：值班员倒在桌前，手还按在键盘上；日志停在 9.13（**这里只是氛围，不做谜题**）

**段落小高点**：你在药柜最底层找到**安全出口钥匙**。

**转折（起的收束）**：拿到钥匙的同时，楼里的广播**响了** ——
「各位住户请注意，一层现已封锁，请返回室内，切勿外出。」
**循环播放的录音。** 你意识到：**这栋楼早就被封过一次。**

---

## 五、承 · 找路（一层各房间，12 分钟）

**这一段的任务**：**在噪音把怪物引进楼里之前，凑齐撤离需要的东西。**

**四件事**（可自由顺序，但拖得越久越难）：

| 事 | 内容 | 恐怖片桥段 |
|---|---|---|
| **救人** | **陈叔**（402 老人）房门反锁。救他 = 拿到**尸王弱点**；不救 = 少一张底牌 | 《釜山行》式的"救不救" |
| **情报** | **阿贵**的话一半真一半假。信错了，车库里要多绕路 | 《闪灵》：他先疯了 |
| **物资** | 药柜、行李箱、储物间 —— 弹药 / 护甲 / 急救包 | 经典"搜刮"段 |
| **线索** | 5 条物证（结算加分），散在各处 | 给探索型玩家的奖励 |

**噪音机制登场**（《寂静之地》）：开枪、破门、奔跑都会把怪引过来。
**玩家在这里第一次学会一件事**：**打不打得过不重要，值不值得打才重要。**

**承段收尾**：你拿着钥匙走到一层安全门 —— **门从外面焊死了**。

---

## 六、转 · 断路（地下车库，8 分钟）

> **本段职责：切断退路 + 交出真相。** 这是全副本从"求生"变成"绝境"的地方。

**第一刀 · 退路断了**（参考《活死人黎明》电梯断电）
- 一层封死、楼梯被卷帘门锁死 → **唯一通道是电梯井，通往地下车库**
- **从这一刻起，你不能回头了**

**第二刀 · 车库是原点**（参考《28 天后》）
- 车库里堆着**防化服、空弹壳、封条** —— 封条日期 **9.12**，比物业报警早一天
- 墙上有人用油漆刷了四个字：**「不许开灯」**
- **你明白了一件事**：**病毒是从这栋楼里出去的。而封楼的人，比病毒先到。**
- 这不是阴谋论，是恐怖片的经典揭底时刻：**官方早就知道，并且他们只封楼、不救人**

**第三刀 · 绝境感**
- 车库里是**本副本最密的一波敌人**（尸犬 + 爬行者）
- **配电箱抉择**：拉闸开灯（视野恢复，但噪音 +5 直接引怪）／摸黑（安全但举步维艰）
- 这里必须有一次**真正的濒死体验**（基因锁觉醒的最佳触发点）

**转段落点**：你从车库爬上来，站在大厅门口。
**灯全亮着，桌椅整齐** —— 整栋楼唯一还像正常地方的空间。
**大厅中央站着一个三米高的东西，穿着保安制服，胸前别着工牌。**
**它是老周。**

---

## 七、合 · 突围（大厅与消防通道，10 分钟）

**大厅**（参考《迷雾》：**看起来最安全的地方最危险**）

**老周 / 尸王**：
- 前保安队长，变异后的巨躯。**左臂畸形**（陈叔的弱点情报：打左臂）
- **行为**：他不主动扑杀，只在**巡逻**。来回踱步，抬手指向每个房间。喉咙坏了，但你能听出他在说一句走调的话：
  > 「请……回到……室内。」
- **他是全副本唯一有"人格"的敌人** —— 因为他还在上班

**Boss 战的三个变数**（让这场战斗不只是血条）：
1. **陈叔情报** → 可打左臂（防御 −1，每场 3 次弱点击破）
2. **噪音** → 战斗中每回合 +1；**噪音 ≥14 触发尸潮**（3 回合内必须结束）
3. **血统失控** → 高排斥角色在此战中失控风险翻倍（血脉被尸气刺激）

**消防通道**：
- 门内侧有血字：**「别开门」**（氛围用，不做笔迹谜题）
- 外面是**封锁线** —— 这栋楼被放弃时，里面的人**没收到通知**

**三结局**（冷峻，参考《迷雾》的结尾语气）：

| 结局 | 条件 | 结算 |
|---|---|---|
| **成功撤离** | 拿到钥匙 + 活着到出口 | 主神只报一句：「**存活率 12%**」 |
| **带人撤离** | 额外救下母女 | 支线奖励入账。**主神不评价** —— 下一次副本她们还是会被扔进来 |
| **陨落** | 死亡 / 超时 | 「评价：D。是否重来？」 |

## 八、人物（按功能设计）

| 人物 | 类型角色 | 功能 | 原型 |
|---|---|---|---|
| **陈叔** | 知情的老住户 | 给尸王弱点（左臂）；救了才有 | 《活死人黎明》的老保安 |
| **阿贵** | 吓疯的幸存者 | 提供噪音机制情报，但一半是假的 | 《闪灵》 |
| **小林** | 被困在车库值班室的值班员 | 阶段 2 的**救援目标** + 大厅情报 | 《釜山行》的乘客 |
| **母女** | 电梯井里求救的两人 | **道德抉择**：救了拖慢撤离、推高噪音 | 《釜山行》 |
| **老周** | 变异的前保安队长 | **Boss**；唯一有人格的敌人 | 《生化危机》的追踪者 |

> **不再给任何人"隐藏身份"或"文学化真相"** —— 每个人只有**一个明确功能**，玩家要能一眼看懂该救谁。

## 十、写作纪律（自我约束）

1. **不写"意义"** —— 只写"怎么活"
2. **不写循环、不写"上一个人"、不写笔迹谜题** —— v2 的毛病
3. **主神是冷的** —— 不出面、不解释、不安慰，只给任务和结算
4. **恐怖来自"退路被切断"** —— 一段一段收掉玩家的选择
5. **每个桥段都能说出参考片** —— 说不出就别写
6. **敌人只有老周有人格** —— 因为他还在上班
