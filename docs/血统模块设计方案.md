# 血统模块设计方案（多血统 + 排斥反应）

> **⚠️ 实测踩坑：装配血统时，节点必须放进 `picked` 数组**
>
> ```gdscript
> # ✅ 正确
> c.bloodlines = [
>     {"id": "infected", "rank": "B", "picked": ["claws", "proliferate"]},
>     {"id": "werewolf", "rank": "B", "picked": ["steel_claw", "blood_moon"]},
> ]
> # ❌ 只给 rank 不给 picked —— 一个节点都不会解锁
> ```
>
> 症状：`bloodline_nodes()` 返回 **空数组**，`bloodline_attr_bonus()` / `bloodline_active_skills()`
> 全部为 0，看起来"血统装上了但完全没效果"。
>
> **`rank` 只决定能选到哪一级，不决定选了哪些** —— 后者由 `picked` 决定。
> 试玩脚本 `tests/real_playthrough.gd` 里有可直接抄的装配示例。

> 两条核心规则：
> **① 血统 = 一条技能树**，可以**同时拥有多条**，但成本递增。
> **② 谱系相冲的血统会互相排斥** —— 排斥越强越危险，100% 直接基因崩溃而亡。

---

## 一、核心张力：贪心是要命的

| | 单血统 | 双血统 | 三血统 |
|---|---|---|---|
| 能力总量 | 一棵树 | 两棵树（build 深度翻倍） | 三棵树（理论最强） |
| 激活成本 | 800 点 | 1,600 点 | 3,200 点 |
| BP 成本 | ×1.0 | ×1.5 | ×2.0 |
| **排斥风险** | 无 | **看谱系搭配** | 几乎必然高危 |

**关键**：排斥不是随机惩罚，而是**可计算的**——玩家在兑换前就能看到「这两条血脉会打起来」。

| 搭配 | 排斥度 | 结果 |
|---|---|---|
| 天使 + 仙体（同为神圣/精神） | **0%** | 完美共存，主力 build |
| 血族 + 义体（混沌 vs 秩序，弱对立） | 26% | 略有折损，可接受 |
| 血族 + 狼人（不死 vs 生命） | 45% | 逼近失控线 |
| **天使 + 恶魔（神圣 vs 邪恶 + 秩序 vs 混沌）** | **65%** | **已进入失控档** |
| 天使 + 恶魔（双双升至 T5） | **100%** | **基因崩溃而亡** |

## 二、谱系标签（决定排斥的底层）

每个血统带 2–3 个**谱系标签**，标签之间有价值不等的对立关系：

| 标签 | 对立标签 | 对立强度 |
|---|---|---|
| 神圣 | 邪恶 | **30** |
| 生命 | 不死 | **25** |
| 秩序 | 混沌 | **20** |
| 物质 | 精神 | **15** |
| 兽性 | 理性 | **15** |

> 只有**互为对立**的标签才产生排斥；标签相同或无关则**不产生排斥**（甚至视为同源）。

**八系血统的标签表**：

| 血统 | 来源世界 | 谱系标签 |
|---|---|---|
| 感染系 | w1 惊变公寓 | 不死 · 混沌 · 兽性 |
| 仙体系 | w2 仙侠 | 神圣 · 生命 · 精神 |
| 义体系 | w3 科幻 | 理性 · 秩序 · 物质 |
| 不死系（血族） | w4 魔法 | 不死 · 混沌 · 物质 |
| 兽化系（狼人） | w5 废土 | 兽性 · 生命 · 物质 |
| **神圣系（天使）** | w4 魔法 · 剧情隐藏 | 神圣 · 秩序 · 精神 |
| **恶魔系（恶魔）** | w4 魔法 · 剧情隐藏 | 邪恶 · 混沌 · 精神 |
| 神性系（外神） | 终局隐藏 | 混沌 · 精神（不可与其他神性共存） |

### 2.1 三种关系：对立 / 互补 / 同源

标签之间不止有「打架」，也有「补足」：

| 关系 | 触发条件 | 效果 |
|---|---|---|
| **对立** | 互为对立标签 | 产生**排斥度**（惩罚） |
| **互补** | 互为互补标签 | 产生**协同度**（助力） |
| **同源** | 标签相同 | 每对相同标签 **+5 协同度**（共鸣） |

### 2.2 互补配对表（每个标签各有 2 个互补，且完全对称）

| 标签 | 对立 | 互补 |
|---|---|---|
| 神圣 | 邪恶 | **生命 · 精神** |
| 邪恶 | 神圣 | **不死 · 混沌** |
| 生命 | 不死 | **神圣 · 兽性** |
| 不死 | 生命 | **邪恶 · 物质** |
| 秩序 | 混沌 | **理性 · 物质** |
| 混沌 | 秩序 | **邪恶 · 兽性** |
| 物质 | 精神 | **不死 · 秩序** |
| 精神 | 物质 | **神圣 · 理性** |
| 兽性 | 理性 | **生命 · 混沌** |
| 理性 | 兽性 | **秩序 · 精神** |

> A 的互补里有 B，则 B 的互补里必有 A —— 因此任意两系血统的关系都是**可预期、可在兑换前预览**的。

### 2.3 协同度公式

```
协同度(%) = Σ 血统对 [ 互补标签对数 × 15 × (1 + 0.1 × (等级A + 等级B)) ] + 同源标签数 × 5  → 封顶 60
```

**推演（神圣系·天使 + 仙体系·仙体 —— 天堂组合）**

天使 = 神圣 · 秩序 · 精神　｜　仙体 = 神圣 · 生命 · 精神

- 对立：**无** → 排斥度 **0**
- 互补：神圣↔生命、精神↔神圣 → **2 对**
- 同源：神圣、精神 → **2 个**

| 阶段 | 协同度 | 获得助力 |
|---|---|---|
| 双双 T1 | 2×15×1.2 + 10 = **46%** | 节点效果 +20%、主动技能共享次数 |
| 双双 T3 | 2×15×1.6 + 10 = **58%** | 解锁协同技 |
| 双双 T5 | 2×15×2.0 + 10 = **70% → 封顶 60%** | 满协同 |

### 2.4 协同的三档助力

| 协同度 | 效果 |
|---|---|
| **10–29%** | 血统节点效果 **+10%** |
| **30–49%** | 节点效果 **+20%**；两条血脉的**主动技能共享使用次数**（用 A 的技能不消耗 B 的次数） |
| **50%+** | 节点效果 **+35%**；解锁**协同技**（正向组合技，无副作用） |

**协同技示例**：

| 搭配 | 协同技 | 效果 |
|---|---|---|
| 天使 + 仙体 | **圣辉剑域** | 范围内敌人受伤并被标记，队友对其命中 +10，持续 2 回合 |
| 血族 + 义体 | **永夜机骸** | 义体过载不耗能量、血族再生翻倍，持续 3 回合 |
| 感染 + 兽化 | **疫兽狂潮** | 变身期间命中附加感染，被感染者死亡时爆出小感染体 |
| 仙体 + 义体 | **灵枢机巧** | 御剑可穿墙，且每次击杀返还 1 点意志力 |

### 2.5 矛盾血脉：排斥与协同同时存在

有些搭配**既互相拉扯又互相激发**，例如：

**血族**（不死 · 混沌 · 物质）+ **狼人**（兽性 · 生命 · 物质）
- 对立：不死↔生命 = **25 排斥**
- 互补：混沌↔兽性、不死↔物质 → **协同**；同源：物质 → **+5**

→ 两个效果**同时生效**（惩罚与助力都真实作用于战斗）。
这类「矛盾血脉」既危险又有爆发力，是高风险高回报的赌博型搭配。

## 三、排斥度公式

```
排斥度(%) = Σ 血统对 [ 对立标签强度之和 × (1 + 0.15 × (等级A + 等级B)) ]   → 封顶 100

其中「等级」= 该血统技能树已解锁到的最深层级（T1=1 … T5=5）
```

**推演（天使 + 恶魔）**：

| 阶段 | 对立强度 | 等级系数 | 排斥度 | 后果 |
|---|---|---|---|---|
| 双双 T1 | 神圣↔邪恶 30 + 秩序↔混沌 20 = 50 | 1 + 0.15×2 = 1.3 | **65%** | 已进失控档 |
| 双双 T2 | 50 | 1 + 0.15×4 = 1.6 | **80%** | 高频失控 + 融合技解锁 |
| 双双 T3 | 50 | 1 + 0.15×6 = 1.9 | **95%** | 每回合几乎必失控 |
| 双双 T5 | 50 | 1 + 0.15×10 = 2.5 | **100%（封顶）** | **基因崩溃** |

> 也就是说：**天使 + 恶魔从兑换那一刻就注定 65% 起步**，玩家只能靠意志力、稳定剂与调和手术把它摁在 50% 以下——
> 而每一次升阶都会把排斥度往上推。这就是「力量越强越接近死亡」的具体机制。

**三血统**的排斥度 = 所有两两配对的**累加**，因此三血统基本必然撞上 100%（除非三条血脉标签全兼容）。

## 四、三档后果

| 排斥度 | 档位 | 效果 |
|---|---|---|
| **0–9%** | 相容 | 无惩罚（同源血脉完全无碍） |
| **10–49%** | **血脉干扰** | 命中 **−10**（≈ −1 个成功）、伤害 **−1**、防御 **−1**（两条血脉互相拉扯） |
| **50–99%** | **失控风险** | 上述惩罚照旧；**每回合开始掷 D10，≤ ⌊排斥度/10⌋ 则失控**：本回合失去控制（跳过行动）+ 血脉反噬 1 点伤害（队伍系统上线后改为「攻击最近单位」，可能打到自己人） |
| **100%** | **基因崩溃** | 战斗/探索结束时角色**永久死亡**（存档中标记阵亡，需重新建卡） |

> **数值标定说明（实测调优）**：本作战斗是**骰池系统**（伤害基数 2–5），不是火纹式百分比。
> 「命中 −10」在代码中换算为 **−1 个成功**（每 10 点命中 ≈ 1 成功）；伤害惩罚从 −2 调为 **−1**——
> 因为 −2 会把基础伤害直接打到 0：实测 120 回合总输出从 249 掉到 **1**，惩罚过重。
> 调优后：高排斥角色输出 ≈ 纯人类的 **50%**（249 → 124）、承伤 **+19%**，同时享有血脉沸腾 +35% 的技能加成。

**失控概率对照**：50% → D10 ≤ 5（50% 概率）；80% → D10 ≤ 8（80%）；95% → D10 ≤ 9（90%）。
高排斥的玩家在关键战斗里几乎一定会失控 —— 这不是"万一"，而是"迟早"。

## 五、缓解手段（玩家的应对工具箱）

| 手段 | 效果 | 成本 / 限制 |
|---|---|---|
| **意志力压制** | 本场战斗排斥度 −10% | 战斗开始时花 2 点意志力 |
| **血脉稳定剂** | 排斥度 −15%，持续 3 回合 | 消耗品（主神兑换 / 副本拾取） |
| **调和手术** | **永久** −20% 排斥度 | 主神空间，成本 = 血统总投入的 30% |
| **专长「共生体质」** | 永久 −25% 排斥度 | 占用一个专长位 |
| **停止升阶** | 排斥度不再上涨 | 放弃该血统树的上层能力 |

> 设计意图：**排斥度是可以管理的资源**，不是一次性判死刑。玩家的操作空间 = 用多少资源去摁住它。

## 六、高排斥的补偿：血脉沸腾

危险必须给回报，否则多血统没有意义：

| 排斥度 | 增益 |
|---|---|
| **≥ 50%** | **所有血统节点效果 +20%**（血脉互相冲撞反而催出力量） |
| **≥ 80%** | 效果 +35%，并解锁**融合技**（两条血脉的组合技能，各树 1 个） |
| **100%** | 无 — 直接死亡 |

**融合技示例**：
- 天使 + 恶魔（≥80%）→ **「堕天裁决」**：对范围内敌人造成 神圣+邪恶 双属性伤害，自身回复伤害的 30%，使用后本场排斥度 +10%
- 血族 + 狼人 → **「血月狂猎」**：变身 3 回合，移动 +3、每次击杀刷新行动
- 感染 + 义体 → **「机械疫病」**：命中使命中目标感染，其死亡时爆炸并扩散

> 于是出现一种**疯批 build**：故意把排斥度堆到 80–95%，靠「血脉沸腾」的加成和融合技打爆发，
> 用意志力与稳定剂把失控概率压到能接受的范围 —— 高风险，高上限，随时可能死。

## 七、血统升级：从 D 级一步步爬

### 7.1 五级评级

血统沿用主神空间的**评级体系**。**兑换时只能选最低的 D 级**，之后必须一级一级往上买
—— **没有"一步到位买 S 级"这条路**。

| 评级 | 名称 | 战力定位 | 技能位 | 升级差价（奖励点） | 世界素材门槛 |
|---|---|---|---|---|---|
| **D** | 初拥 | 入门异能 | 3 选 2 | 800（激活） | 对应世界基础素材 ×1 |
| **C** | 觉醒 | 明显超常 | 4 选 2 | 1,600 | 血脉结晶 ×2 |
| **B** | 成熟 | 精英轮回者 | 4 选 2 | 4,800 | 精英素材 ×1（精英怪掉落） |
| **A** | 大君 | 顶尖战力 | 3 选 2 | 14,400 | Boss 素材 ×1 |
| **S** | 始祖 | 世界级 | 2 选 1 | 43,200 | 隐藏素材 ×1（唯一、不可交易） |

- 累计成本：D 800 → S 共 **64,800 点**（≈ 8–10 个副本的收益），与五界长线节奏吻合
- **素材门槛全部绑定世界** → 逼迫玩家跨世界探索，而不是在一个副本里刷满

### 7.2 每级「解锁几个、只能选几个」

**这是升级系统的核心**：每升一级，树上**解锁一批候选技能（3–4 个）**，
但**只能选其中 2 个**（S 级只能选 1 个）。因此**同级玩家的血统 build 必然不同**。

| 评级 | 候选技能 | 可选 | 设计目的 |
|---|---|---|---|
| D | 3 | **2** | 入门即分化 |
| C | 4 | **2** | 第一条路线成型 |
| B | 4 | **2** | 路线深化 |
| A | 3 | **2** | 形态/大招抉择 |
| S | 2 | **1** | 终极定型 |
| **合计** | **16** | **9** | 满级血统共 9 个技能位 |

**升级前置**：必须先把**当前评级的选择点满**（D 级选满 2 个才能升 C 级），
杜绝"攒钱直升、技能空着"的玩法。

**洗点**：可重置**某一级**的选择（返还该级投入，评级不变）；
重置整条血统评级需「血脉净化」，成本 = 该血统总投入的 50%。

### 7.3 完整示例：不死系 · 血族（D → S）

```
D 级 · 初拥（3 选 2）
 ├ [鲜血感知]  被动：探测 4 格内的生物
 ├ [夜之亲和]  被动：夜间（黑暗地形）命中 +5、回避 +5
 └ [血色体质]  属性：耐力 +1

C 级 · 觉醒（4 选 2）
 ├ [血之蛮力]  被动：近战伤害 +1
 ├ [汲血]      主动：命中后回复 3 HP（每场 3 次）
 ├ [疾影]      被动：移动力 +1
 └ [蝠步]      主动：本回合穿墙移动 2 格（每场 2 次）

B 级 · 成熟（4 选 2）
 ├ [血怒]      被动：生命 <50% 时伤害 +2
 ├ [钢铁血脉]  属性：耐力 +1、防御 +1
 ├ [回旋]      被动：击杀后可再移动 1 格
 └ [毒牙]      被动：命中附加流血（每回合 −1 HP，持续 2 回合）

A 级 · 大君（3 选 2）
 ├ [血之觉醒]  形态：3 回合内 力量 +2 / 敏捷 +2，结束眩晕 1 回合
 ├ [黑暗形态]  形态：3 回合内 防御 +3、每回合回 2 HP，移动 −1
 └ [蝙蝠群]    主动：召唤 2 只蝙蝠牵制敌人（每场 1 次）

S 级 · 始祖（2 选 1）
 ├ [始祖 · 血河]  每场 1 次：范围吸血（伤害 = 力量×2，回复 50%）
 └ [始祖 · 不朽]  被动：生命归零时以 30% 生命复活（每副本 1 次）
```

> 同样一个血族：选 `[汲血] + [血怒]` 是**续航爆发流**，选 `[钢铁血脉] + [黑暗形态]`
> 是**坦克流** —— 16 个候选、9 个技能位，足够撑出多种打法。

### 7.4 与排斥度 / 协同度的联动

- **血统评级 = 排斥公式里的「等级」**（D=1 … S=5）→ **每次升级都会推高排斥度**
- 协同公式同样吃评级 → **升级也会放大互补搭配的助力**
- 因此高评级多血统是**双向放大**：助力更大、失控风险也更大 —— 这正是玩家要权衡的核心

### 7.5 主神空间 UI（血统页）

```
┌─ 不死系 · 血族 ── 评级 D → C ─────────────────────────┐
│ 排斥度 [██░░░░░░░░] 12%      协同度 [████░░░░░░] 41%  │
├───────────────────────────────────────────────────────┤
│ D 级 初拥   已选 2/2   ●鲜血感知   ●夜之亲和          │
│ C 级 觉醒   候选 4 选 2（需 1,600 点 + 血脉结晶 ×2）  │
│    ◇血之蛮力    ◇汲血    ◇疾影    ◇蝠步               │
│    [ 升级到 C 级 ]  ← 灰：素材不足（血脉结晶 0/2）    │
├───────────────────────────────────────────────────────┤
│ 升级预览：评级 D→C 后，排斥度 12% → 19%               │
│           （若同时持有「天使」：71% ⚠ 失控档）        │
└───────────────────────────────────────────────────────┘
```

**升级预览必须显示排斥度 / 协同度的变化** —— 让玩家在「变强」与「变危险」之间做清醒选择。

## 八、成本与解锁

| 项 | 第 1 血统 | 第 2 血统 | 第 3 血统 |
|---|---|---|---|
| 激活（奖励点） | 800 | 1,600 | 3,200 |
| BP 成本倍率 | ×1.0 | ×1.5 | ×2.0 |
| 解锁条件 | 通关 1 个世界 | 通关 2 个世界 | 通关 4 个世界 |

## 十一、验收清单

1. 未激活血统时行为与现状完全一致；已激活单血统时排斥度为 0。
2. 天使 + 恶魔（双双 T1）计算出的排斥度 = 65%，且 UI 标为「失控档」。
3. 排斥度 10% 起立即看到命中/伤害/防御的下降（战斗日志有明确提示）。
4. 排斥度 ≥50% 时每回合真实掷骰并可能失控（失控时真的会打队友）。
5. 排斥度达到 100% 时角色确实会死亡并被存档记录（不是提示文字）。
6. 双双升阶会把排斥度持续推高（等级系数真实参与计算）。
7. 四种缓解手段全部生效，且能组合使用把 65% 压到 50% 以下。
8. 排斥度 ≥50% 时血统节点效果提升 20%（可验证的具体数值变化）。
9. 排斥度计算是**纯函数**并有单元测试（给定标签与等级，输出确定值）。
10. 互补搭配（天使 + 仙体）双双 T1 时：协同度 **46%**、排斥度 **0%**，节点效果 +20% 可见。
11. 协同度 ≥30% 时两条血脉的主动技能**共享使用次数**（用 A 的技能后 B 的剩余次数不变）。
12. 协同度 ≥50% 时解锁**协同技**，且协同技**没有副作用**（与高排斥的融合技明确区分）。
13. 「矛盾血脉」（同时有排斥与协同，如血族 + 狼人）时，两个效果**同时生效**。
14. 兑换前预览同时显示**排斥度与协同度**的预测值（含三档阈值刻度）。
15. 兑换时**只能选 D 级血统**，界面中不存在"直接购买 S 级"的路径。
16. D 级只能选 2 个技能；**没选满 2 个时无法升级到 C 级**（前置校验生效）。
17. 每次升级都推高排斥度（评级 = 等级，真实参与公式），且 UI 出现升级预览。
18. 升到 S 级时终极技能**只能选 1 个**，另一个在本周目内不可得（洗点后可选另一个）。
19. 同一血族的两条路线（续航爆发流 / 坦克流）在实战表现上**明显不同**（不是数值微调）。
