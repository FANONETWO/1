### 已完成的主线

**核心玩法**

1. **箱庭探索** —— 12 个独立箱庭（单房间级 9~20 × 4~7）。走到门格只切换地图数据、**不换 `.tscn`**，
   所以战斗 overlay、敌人状态、掉落全都跨房间保留
2. **回合制潜行** —— 90° 视野锥 + 迷雾 + 已探索记忆。被察觉进入**追逐**：
   敌人朝你或最后已知位置推进，**贴到身上（曼哈顿 ≤1）才开战**，刚发现你的那回合先愣一下，追丢 3 回合放弃
3. **CTB 行动条战斗** —— `av += 1000 / speed`，速度高者出手更频繁；顶部列出未来 8 次出手；
   **指挥点**（队内最高智力/2）可「抢手 / 压制」干预顺序
4. **双模式** —— 独狼（奖励 ×1.5 风险溢价）／四人小队（3 名预设队友），成绩按 `id@mode` 分开记
5. **D10 骰池** —— 掷「属性 + 技能」枚，每枚 ≥8 记 1 成功，10 可追加；成功数 ≥ DC
6. **九属性全部有战棋出口** —— 移动力 / 暴击 / 生命 / 指挥点 / 光环 / 威慑 / 首击减伤 / 意志池，
   不再是"9 项里 5 项没用"

**系统**

7. **血统** —— 10 系 × D→S 五级 × 四层节点；排斥度、失控、基因锁、绝境爆种
8. **噪音机制** —— 阈值 6/10/14 分别召唤逐尸/爬行者/尸群；按回合衰减，换房间归零
9. **任务与剧情** —— 阶段 1 已落地：开场简报、6 条物证线索、陈叔/阿贵对话树、三结局结算
10. **存档 v3** —— 模式化成绩键、v1→v2→v3 完整迁移链

**表现与工程**

11. **明日方舟风格 UI** —— 主题/画框/背景三层自绘（`ui/ak_*.gd`），5 步建卡向导
12. **火纹式战斗演出** + 程序化像素美术（tile/立绘/图标全由脚本生成，零外部美术）
13. **音频** —— 19 音效 + 3 首 BGM，`AudioManager` 单一播放入口，M 键静音
14. **新手引导** —— 首次进副本自动三步引导，可跳过、可随时重看
15. **测试与工具链** —— 35 项测试 + 一键回归（超时/时间戳）+ **实机验收脚本**（真实鼠标输入）+ `DebugLog`

## 二、本轮做的事

### A. 潜行与追逐（此前这块基本不可玩）

| 项 | 内容 |
|---|---|
| **修 4 个视野 bug** | ① 换房间不重算视野 → 进屋后一个视野格都没有 ② 缓存签名漏了朝向 → 巡逻兵转身后视野锥冻结在旧位置 ③ 只画最近一个敌人的锥 ④ 锥角实为 180°，与"背后 = 突袭"的承诺矛盾 |
| **改为追逐制** | 进视野只标记 `alerted`，**不再立刻开战**；敌人朝你 / 最后已知位置推进；曼哈顿 ≤1 才接触开战；追丢 3 回合放弃 |
| **视野数值的真实结论** | 曾为"潜行太难"把丧尸视野压到 2 格 —— 实机一测发现完全相反：2 格内发现、1 格接触、敌人一回合走 1 格，三段挤在同一瞬间，**追逐形同虚设**。改为 3 格 + 90° 锥 + 背后接近，潜行空间靠**锥角**给，不是靠把视野勒到看不见 |
| **新增反应窗口** | 察觉你的那一回合敌人**原地不动**，下一回合才起步 —— 否则"被发现"与"被抓住"会挤在同一瞬间 |
| **实机验收** | `tools/playtest/chase_playtest`：真实鼠标点击走位，8 项断言全过（含**逐帧采样**抓到"已在追但还没开战"的瞬间）|

### B. 术语与决策记录（装了两个技能后第一次真正用上）

- 新增 **`GLOSSARY.md`**：按"有主见地选一个词、其余进 `_Avoid_`"的纪律，裁定了 4 处**真冲突**：
  `战术点` vs `指挥点`（同一概念两个名字、**数值还不一样**）／ `积分` vs `奖励点` ／
  `副本` vs `影片` ／ `团队模式` vs `小队模式`
- 新增 **`docs/adr/` 6 条**：CTB 行动条 / 独狼 ×1.5 是风险对价 / 视野锥 90° 与愣一回合 /
  首页 README 刻意留空 / 逻辑层不依赖 autoload / 美术音频全部程序化
- 据此统一代码：`Character.tactical_points()` → `command_points_base()`，角色面板、HUD、
  属性说明的用词全部对齐（8 文件 10 行）

### C. 音频：从正弦波换成真实音源

- **免费方案调研**：`dsh-midi-studio`（FluidSynth WASM 本地渲染）自带测试 **40/40 通过**，
  但挂进 profile 被**版本守卫拒绝**（peer 要求 `dsh-tools ^0.1.0-rc.6`，本机 `0.2.0-rc.2`，
  系统警告可能崩溃与数据丢失）
- **没有开风险豁免**，改为直接调用它的引擎 —— 其 `lib/lib/*.js` 不 import 任何 DSH API，
  于是当普通 JS 库用：**不装插件、不动 profile、零兼容风险**
- **三首 BGM 按剧本基调重做**：explore 屏息留白（《寂静之地》）／ battle 机械紧迫、无旋律（《28 天后》）／
  hub 非人的冷（**刻意不用弦乐** —— 弦乐有人味，主神不该有）
- **无缝循环**：越界持续音 + 尾巴交叉淡化 + 末段微对齐 → **首尾样本差为 0**，
  接缝曲率远低于信号内部 p99
- `gen_audio.py` 摘掉 BGM 职责（从此只生成 19 个音效）；已验证重跑它后三首 BGM 的 sha256 不变
- `assets/CREDITS.md` 新增第六节登记音频版权（含音色库的**残余溯源风险**与两条替代方案）
