## 二、场景氛围文本（进入时显示 3~5 句）

### 2.1 一层 · 楼梯间（开场）
> 你是被冷醒的。
> 水泥地面，一道防火门半开着，门后的走廊没有灯。
> 手环亮了 —— 不是时间，是一行字。
> 远处有什么东西在拖行，很慢，一下，一下。

### 2.2 一层 · 走廊
> 应急灯每隔三米一盏，绿光，够你看清地面。
> 墙上的消防栓玻璃碎了一地。地上有拖痕，从走廊一头延伸到另一头。
> 拖痕是湿的。

### 2.3 值班室
> 灯还亮着，日光灯管在闪。
> 一个穿制服的人趴在桌上，手还按在键盘上。他已经不动了。
> 桌上的日志摊开着，停在一页写好一半的记录上。
> 空气里有铁锈味。

### 2.4 402 门前（陈叔）
> 门是防盗门，三道锁全锁着。
> 门缝下透出一线光 —— 里面有人，而且点了灯。
> 你靠近的时候，门后的动静停了。
> 过了很久，一个很轻的、极慢的哼歌声又响起来。

### 2.5 楼梯间（封死）
> 卷帘门放到了底，边缘焊了一圈铁条 —— 焊口还很新。
> 这不是意外，是有人专门干的。
> 旁边的电梯井门被撬开了，井道里一片黑。
> 往下，是地下车库。

### 2.6 地下车库
> 没有灯。你的眼睛适应了很久，也只看得见五步以内。
> 空气是凉的、湿的，带着汽油和别的东西混在一起的味道。
> 你听见远处有水在滴。还有别的 —— 某种很轻的、贴着地面移动的声音。
> 你每走一步，声音都比你大。

### 2.7 车库 · 配电箱
> 配电箱的门敞着，里面被人用油漆刷过字。
> 四个字：「不许开灯」。
> 刷得很急，油漆顺着往下流。
> 总闸就在你手边。

### 2.8 车库 · 值班室（小林）
> 门是从里面锁的。
> 你敲了三下，里面的电波声停了。
> 一个女人的声音，很轻：「……你是谁？」
> 她说话时，你注意到钥匙还插在门内侧的锁孔上。

### 2.9 大厅（尸王 · 老周）
> 灯全亮着。
> 桌椅摆得整整齐齐，地砖擦过，前台的花瓶甚至还是正的。
> 这是整栋楼里唯一像样的地方。
> 大厅中央站着一个东西 —— 三米高，皮肤像烧过的水泥，左臂是畸形的。
> 它没有扑过来。它在来回踱步，抬手指向每一个房间的方向，然后放下手，再走回去。

## 三、对话树

### 3.1 陈叔（402 · 一层）

**触发**：走到 402 门前（门后有哼歌声）

```
[敲门]
├─ 门后沉默五秒
│  └─ 陈叔（隔着门）：「别敲了。走吧。」
│
├─ A「我是来帮忙的。」
│  ├─ 陈叔：「帮忙？你连自己都保不住。」
│  │  └─ 选项：
│  │     ①「值班室有降压药，我给你拿来了。」      → 需持有降压药 → 【开门】
│  │     ②「楼里还有别人活着。」               → 检定：风度+说服 DC 3
│  │          成功 → 【开门】
│  │          失败 → 陈叔：「你走吧。」（可再来一次）
│  │     ③「那我走了。」                        → 离开
│
└─ B「里面还有谁？」
   └─ 陈叔（很久）：「……没谁。」
      └─ 提示：他没说实话。（不做支线，只是氛围）
```

**【开门】之后**：
> 陈叔只开了一条缝，链子没摘。他六十多岁，眼窝很深，手里握着一把菜刀。
> 「你要出去？」
> 「一层门焊死了，你还不知道吧。」
> 「往下走。车库。那儿有条道。」
> 「……大厅里那个东西，以前是这儿的保安。姓周。」
> 「他左边胳膊不行。你要真打不过，就往那儿招呼。」

**获得**：尸王弱点情报（左臂，防御 −1）
**任务**：支线「老邻居」→ 标记为已救

**注**：若拒绝救他，陈叔不开门，尸王弱点情报**无法获得**。

### 3.2 阿贵（一层消防栓后）

**触发**：靠近

```
阿贵：「你也是被扔进来的？」
阿贵：「嘘 —— 别那么大声。它们听声音。」
```

```
├─ A「你说什么？」
│  └─ 阿贵：「声音！它们靠声音找人！我躲管道里三天，一声不敢出！」
│     └─ 【可信情报】噪音机制说明
│
├─ B「车库里有多少？」
│  └─ 阿贵：「二十只！黑压压一片！我数过！」
│     └─ 检定：感知+洞察 DC 3
│        成功 → 你看出来他在夸大。他其实没数清。
│              （实际车库敌人远少于二十）
│        失败 → 你信了，阶段 2 会绕远路（噪音累积）
│
└─ C「跟我走。」
   └─ 阿贵：「不。我就在这儿。这儿有墙。」
      （他不会加入）
```

**关键功能**：把**噪音机制**告诉玩家（借疯子之口，比系统提示自然）。

### 3.3 小林（车库值班室 · 无线电）

**触发**：阶段 2，听到电波声后敲门

```
小林：「……你是谁？」
（对话选项）
├─ A「来救人的。」
│  └─ 小林（很久）：「……别过来。你过来会把它引过来。」
│
├─ B「大厅里是什么？」
│  └─ 小林：「一个保安。姓周。他还在巡逻。」
│     「他左边胳膊……算了，你自己看吧。」
│     └─ 【情报】尸王左臂（与陈叔情报重复，互为备份）
│
└─ C「你怎么知道这么多？」
   └─ 小林：「我在这儿三天了。」
      「值班室的监控还能用。就大厅那个探头没坏。」
      └─ 【情报】可查看大厅监控（提前看到尸王）
```

**后续**：她被救出后不再出现（她的功能到此为止，**不给她额外剧情**）。

### 3.4 母女（电梯井口 · 阶段 2）

**触发**：经过电梯井时听到喊声

```
母亲：「下面有人吗！下面有人吗！」
母亲：「我女儿还在……你能不能——」
```

```
├─ A「待在原地！别动！」
│  └─ 检定：风度+说服 DC 3
│     成功 → 她们答应等 → 撤离时由消防梯接应（结局加成）
│     失败 → 她们慌了，跑出房间 → 噪音 +2/回合
│
├─ B「我上不去，你们自己想办法。」
│  └─ 母亲沉默。之后楼层安静下来。
│
└─ C（不回应）
   └─ 喊声持续了很久，然后停了。
```

**结局时**（若成功救下）：
> 母亲抱着孩子从那扇门出来，看见你，问了一句：
> 「外面那些人……是来救我们的吗？」
> （玩家没有回答选项 —— 系统不给回答）

## 五、老周（尸王）台词

**他是全副本唯一有台词的敌人。总共只有一句话。**

### 5.1 初见（大厅，战前）
> （踱步声）
> 「请……」
> 「回到……」
> 「室内……」

### 5.2 战斗中（每次他行动时，随机一句）
> 「请回到……室内。」
> 「……请……回到……室内。」
> 「回到室内。」

### 5.3 倒下时（唯一一处非台词的表达）
> 他单膝跪下来，用那只能动的右手撑住地面，然后——
> 抬起来，按在胸前工牌的位置。
> 动作很慢，也很标准。

**设计说明**：不做台词解释，不加旁白。**他是保安，他在上班，他一直没下班。**
