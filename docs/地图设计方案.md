# 地图设计方案（惊变公寓 · 一层 v2）

> 本文回答一个问题：**为什么现在的地图不好，应该怎么改，别的游戏怎么做的。**
> 配套样例图：`assets/raw/_probe/map_design_v2.png`（渲染脚本 `tests/shot_map_design.gd`）。

---

## 一、现状诊断

| 问题 | 表现 | 后果 |
|---|---|---|
| **房间没有意义** | 大片重复的「房间地板」格子铺满内部 | 视觉单调，玩家记不住空间，探索像在色块里走 |
| **战术地形全没用上** | `H 高地 / R 废墟 / F 森林 / X 危险区 / T·C·B 掩体` 在 `GridWorld` 里都实现好了，地图上几乎一个都没有 | 战斗退化成「平地互砍」，战棋深度为零 |
| **动线是水管** | 一条走廊直插到底，没有环 | 无法包抄、无法撤退，只能一路平推 |
| **门只是装饰** | 门不构成关卡 | 丢掉「一夫当关」这个战棋最核心的乐趣 |
| **没有探索节奏** | 全图一次性摊开 | 没有未知感，没有「开图」的爽点 |

一句话：**系统做完了，地图没跟上。** 地形数值全都在，只是没人把它们摆进关卡里。

## 二、五个游戏案例（各自解决什么）

### 1.《生化危机 2 / 4》—— 箱庭（Sandbox Mansion）
- 核心：**小而密的房间 + 钥匙锁链 + 回头路**
- 每个房间有唯一记忆点（打字机、雕像、道具箱）；玩家反复穿越同一空间，每次因新钥匙获得新意义
- **对我们的价值**：无限流副本最该学的就是它。一层 6 个房间的尺度刚刚好，「钥匙开锁 → 回头路」直接对应我们的道具/任务链

### 2.《火焰纹章》—— 战术地形
- 核心：**地形改变战斗数学**（森林回避 +15、高地命中 +10、窄桥一次只能过一人）
- 关卡围绕「必守之口」与「必争之高地」设计，玩家的移动选择就是策略
- **对我们的价值**：`GridWorld.TERRAIN` 已经实现了 `avoid / defense / hit_bonus`，**只差把地形摆进地图**

### 3.《博德之门 3》—— 垂直与互动
- 核心：**多层空间 + 可交互物**（推箱、高台落差、油桶爆炸），同一场战斗可从多个入口发起
- **对我们的价值**：`S 楼梯`与`T/C/B 掩体`就是雏形；后续可加「可破坏掩体」「从二楼跳下偷袭」

### 4.《XCOM》—— 掩体与视线
- 核心：**半掩体 / 全掩体 + 侧翼包抄**，地图本质是「掩体的拓扑」，不是好看的美术
- **对我们的价值**：走廊里的桌椅应当被**当作掩体线来摆**，而不是随便点缀

### 5.《暗黑地牢》—— 探索节奏
- 核心：**走廊 = 消耗，房间 = 事件/战利品**，加上迷雾与黑暗中的资源抉择
- **对我们的价值**：探索场景需要「未探索区域不可见 + 已探索保留记忆」

## 三、改进方案（一层 v2）

### 3.1 结构：RE2 箱庭（已落地）

参考《生化危机 2》警察局一层：**北侧房间群 → 横向主走廊 → 中央大堂 → 南侧出口/楼梯**，
左右各一道门构成**环形动线**（可绕圈、可包抄、可撤退）。

```
####################
#CC.#....HH.#..B...#     北侧：储物间 │ 值班室(高地) │ 客房
#...D.......D......#
#...#.......#..C...#
##D##.......##D#####     ← 每房一门 = 窄口防守点
#..................#     横向主走廊（贯通东西，遭遇战主轴）
#...####..####.....#
#...#........#.....#     中央大堂（开阔，含危险区 X）
#...#...X....#..T..#
##D##........##D####     ← 第二组门：这才是"环"的关键
#....D..E....#..S..#     南侧：出口(E) │ 楼梯间(S)
####################
```

| 设计手法 | 具体做法 | 期望效果 |
|---|---|---|
| **环形动线** | 上下两组门 + 贯通的东西走廊 | 可以绕圈包抄，也可以从另一侧撤退（RE2 的"回头路"） |
| **房间语义化** | 每房有功能与专属地形（储物间=柜、值班室=高地、客房=床） | 玩家用「值班室」而不是坐标记路 |
| **窄口战术** | 每房一门，门宽 1 格 | 玩家可以选择「守门」而不是冲出去 |
| **高地争夺** | 值班室 2×2 高地（命中 +10） | 值得为它冒险的战术目标 |
| **危险区** | 大堂火场（每回合 −2 HP） | 制造「绕行 or 硬吃伤害」的抉择 |
| **出口在深处** | 出口需钥匙（已有逻辑） | 钥匙成为整层的动线枢纽 |

### 3.2 地板与墙的重做（已落地）

原来地板与墙都是相似的蓝灰花纹，**几乎分不清哪里能走**。现改为程序化生成
（`tools/make_tiles.py`，无需 AI 额度、像素级完全可控、可复现）：

| 素材 | 色数 | 设计 |
|---|---|---|
| `floor.png` | 3 | **平坦明亮**：底色 108 + 每 8px 瓷砖缝 + 稀疏污渍；视觉上"空"，不抢注意力 |
| `wall.png` | 5 | **厚重暗色**：受光顶边 + 阴影底边 + 错位砖缝 → 一眼看出是实体 |
| `door.png` | 3 | 木色门板 + 门框暗边 + 金色门把 |

关键手段是**刻意拉大明度差**（地板 ≈108 vs 墙 ≈48），而不是靠花纹区分。


### 3.2 落地优先级

| 优先级 | 事项 | 工作量 |
|---|---|---|
| P0 | 把 v2 地图接进 `worlds/registry.gd` 的 w1 阶段 1，同步敌人/NPC/交互点坐标 | 小 |
| P0 | 补 4 张缺失地形素材：高地 `H`、危险区 `X`、废墟 `R`、森林 `F`（素材缺失时用占位色，已配好） | 中（等 Leonardo 额度） |
| P1 | 探索场景加**战争迷雾**：未探索格黑屏，走过留下记忆 | 中 |
| P1 | 门做成**可交互**（开/锁/砸开），锁门需对应钥匙 | 中 |
| P2 | 掩体可破坏（桌子被打碎后防御归零） | 大 |
| P2 | 多层结构：楼梯真的换图，而不是换标签 | 大 |

## 四、素材缺口（需生成）

| 地形 | 字符 | 现状 |
|---|---|---|
| 高地 | `H` | 缺素材（用土黄占位） |
| 危险区 | `X` | 缺素材（用暗红占位） |
| 废墟 | `R` | 缺素材（用灰褐占位） |
| 森林/植被 | `F` | 缺素材（用深绿占位） |

> 提示词建议：`pixel art 16x16 tile, top-down, rubble/grass/elevated platform/burning floor, limited palette, no anti-aliasing`。
> 生成后放 `assets/tiles/w1/{highland,hazard,rubble,grass}.png` 并在 `pixel_grid_renderer.gd` 的 `tile_paths` 登记。
