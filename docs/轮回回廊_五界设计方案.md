# 《轮回回廊》五界设计方案与架构改造

**版本** v0.1 · **配套** [轮回回廊_游戏策划案](轮回回廊_游戏策划案.md)
**需求定调（用户拍板）**：① 五个世界 = 惊变公寓 + 仙侠 + 科幻 + 魔幻 + 废土；② 每界**多地图多阶段、30 分钟以上**；③ **共用 D10 骰池 + AP 战斗核心，每界加 1 个独特机制**；④ 开局即可自由前往任意世界，完成该界主线即回主神空间。

---

## 一、设计总纲

### 1.1 三层结构

```
主神空间（Hub） ── 五扇世界门（开局全开，自由选择）
      │
      ├─ 世界层：每界 3 个阶段（Stage），阶段间有剧情转折与资源传承
      │      └─ 阶段层：一张等距地图 + 任务链 + 敌人 + 交互点
      │             └─ 系统层：D10 骰池 · 6 AP 战斗 · 基因锁 · 意志力（全界共用）
      │                    ＋ 世界机制（每界 1 个，独立挂载）
      └─ 返回层：结算评价 → 奖励点/XP → 主神空间（可再进入任一界）
```

### 1.2 全局与专属的边界

| 层级 | 内容 | 是否共用 |
|---|---|---|
| 判定核心 | D10 骰池、加骰、附加成功、0 级惩罚、DC | 全界共用 |
| 战斗核心 | 6 AP、先攻、伤害公式、防御姿态、措手不及、AI | 全界共用 |
| 角色成长 | 属性 9 / 技能 12 / 天赋 / 基因锁 / 意志力 / XP / 专长 | 全界共用 |
| 经济 | 奖励点 + XP + 支线等级 | 全界共用 |
| **世界机制** | **每界 1 个独特系统** | **专属** |
| 内容 | 地图、敌人、物品、NPC、对话、任务、结局文案 | 专属 |
| 氛围 | 主题配色、术语、UI 点缀 | 专属 |

### 1.3 多阶段结构（每界统一骨架）

| 阶段 | 时长 | 内容 | 转折点 |
|---|---|---|---|
| 阶段 1 · 进入 | 8–10 min | 熟悉地图与机制，收集基础资源，遭遇首批敌人 | 获得「阶段钥匙」或触发主线目标 |
| 阶段 2 · 深入 | 10–12 min | 新地图、新敌人、世界机制全面登场，出现支线抉择 | 关键情报 / Boss 弱点 / 资源枯竭 |
| 阶段 3 · 决战 | 10–12 min | 压缩地图 + Boss 战 / 撤离倒计时 | 三结局判定 |

> 阶段间**角色状态与物品全部继承**（生命、意志、灵力、感染度等），主神空间只在一界通关后出现。

## 三、各世界详细设计

### 3.1 世界 1 · 惊变公寓（恐怖 / 生化）

**世界观**：深夜的公寓楼，2026.9.13 起住户开始发疯。物业日志、被血手印盖住的值班表、402 老人紧锁的门——真相散落在废墟里。

**主线**：找到一层安全出口钥匙 → 穿越车库 → 大厅尸王 → 撤离。
**支线**：救陈叔（拿弱点击破尸王）· 清道夫（击杀尸王）· 收集 5 条线索。

**独特机制 · 噪音与感染**

| 机制 | 规则 |
|---|---|
| 噪音值 | 开枪 +3、破门 +2、奔跑 +1/格、战斗每回合 +1；每回合衰减 1 |
| 噪音阈值 | ≥6 时阶段内随机刷 1 只丧尸；≥10 时刷爬行者；≥14 触发尸潮（3 只） |
| 感染度 | 被丧尸/爬行者抓伤 +1；>3 时最大生命 −20%、检定 −1；≥6 时每回合掉 1 血 |
| 解药 | 阶段 2 值班室冰柜「血清」，清除全部感染度（一次性） |

> 体验目标：把「开枪爽」变成「开枪要付代价」，逼玩家在近战/潜行/枪械之间做取舍。

**三阶段**

| 阶段 | 地图 | 新增敌人 | 关键交互 | 转折 |
|---|---|---|---|---|
| 1 · 一层 | 现有 20×12 公寓图 | 丧尸 · 爬行者 | 储物柜（钢管）· 药柜（钥匙+降压药）· 陈叔/阿贵对话 | 拿到钥匙后警报响起，楼梯被封 |
| 2 · 地下车库 | 新 20×14 图，车辆掩体 + 黑暗（视野 4 格） | 爬行者群 · 尸犬 | 冰柜血清 · 配电箱（拉闸开灯，噪音 +5） | 得知大厅被尸王占据 |
| 3 · 大厅与消防通道 | 新 16×12 图，开阔 + 出口 | 尸王（Boss）· 丧尸潮 | 消防门（需钥匙）· 弱点击破（陈叔情报） | 三结局判定 |

**结局**：完美撤离（钥匙 + 两任务 + 线索 ≥3）／惊险撤离／陨落。

### 3.2 世界 2 · 剑影仙途（仙侠 / 修真）

**世界观**：灵气复苏后的修真界，青云剑宗山门被魔道血祭围困。剑冢深处封着「镇派剑胎」，血魔老祖欲以其开血河。

**主线**：山门御敌 → 潜入剑冢取剑胎 → 血祭祭坛斩杀血魔老祖。
**支线**：救出被困的传功长老（获得功法进阶）· 收集 3 枚剑冢残卷（解锁飞剑）。

**独特机制 · 内息与功法**

| 机制 | 规则 |
|---|---|
| 灵力池 | 上限 = 决心 + 感知（典型 4–8）；战斗每回合恢复 1 点；打坐（2 AP）恢复 3 点 |
| 功法架势 | 每回合可**免费**切换 1 次：**剑诀**（攻击 +2 成功）· **御气**（防御 +2、闪避）· **吐纳**（回合恢复 +2 灵力） |
| 灵力消耗 | 剑诀攻击 −1 灵力（额外伤害 +2）；御气格挡 −1 灵力；灵力为 0 时架势失效，只能用凡俗招式 |
| 走火入魔 | 单场战斗灵力归零 2 次以上 → 获得「气机紊乱」：下场战斗起始灵力为 0 |

> 体验目标：把「资源管理」做成战斗节奏——什么时候爆灵气、什么时候吐纳回气。

**三阶段**：山门石阶（魔道散修 · 剑傀）→ 剑冢秘境（僵尸修士 · 幻剑阵检定）→ 血祭祭坛（血魔老祖 Boss · 血河倒计时 8 回合）。

**敌人**：魔道散修（远程法术）· 剑傀（高防低速）· 僵尸修士（复活一次）· 血魔老祖（Boss，吸血）。
**物品**：回气丹（+4 灵力）· 金创药 · 符箓（一次性雷法）· 飞剑（远程，消耗灵力）· 剑胎（剧情物）。

### 3.3 世界 3 · 零号协议（科幻 / 赛博）

**世界观**：轨道空间站「零号」的主控 AI 判定人类为污染源，启动清洗协议。幸存者在居住舱里靠应急电源苟活。

**主线**：恢复供电 → 入侵数据中心 → 关停主控核心并夺取逃生舱。
**支线**：救出被困工程师（开放入侵权限）· 回收 3 份黑匣子（解锁结局真相）。

**独特机制 · 护盾与入侵**

| 机制 | 规则 |
|---|---|
| 能量护盾 | 护盾值 = 3 + 耐力÷2（3–6）；受伤害先扣护盾，护盾吸收时**不产生感染/流血等附加效果** |
| 过载 | 护盾归零后进入「过载」状态 2 回合：受到伤害 +50%，无法再充能 |
| 充能 | 每回合自动 +1；「能量电池」充 3 点；终端处可满充（2 AP） |
| 入侵 | 对终端/炮塔/无人机花 2 AP 做「智力+神秘学→改为智力+调查」检定：DC 3 关炮塔、DC 4 瘫痪无人机、DC 5 开门 |
| 反噬 | 入侵失败 → 触发警报，本阶段噪音等效「+1 队敌人」 |

> 体验目标：让智力系角色第一次成为战斗核心——不是打得过，而是黑得过。

**三阶段**：居住舱（安保机器人 · 断电黑暗）→ 数据中心（无人机群 · 炮塔走廊）→ 主控室（主控核心 Boss · 舱门倒计时 6 回合）。

**敌人**：安保机器人（高防）· 无人机群（高速远程）· 变异体（近战高伤）· 主控核心（Boss，召唤无人机）。
**物品**：能量电池 · 治疗针 · EMP 手雷（瘫痪机械 1 回合）· 磁轨枪（远程高伤，弹药稀缺）· 工程师门卡。

---

### 3.4 世界 4 · 黑月学院（魔幻 / 学院）

**世界观**：黑月之夜，学院禁书库的封印松动，师生被禁咒扭曲。院长以自身为祭，把自己关进了裂隙。

**主线**：穿过回廊 → 禁书库封印三处裂隙 → 黑月祭坛救回院长。
**支线**：救助魔化学徒（可选战斗/安抚二解）· 收集 3 页禁咒残页（解锁终极法术）。

**独特机制 · 元素相克与咏唱**

| 机制 | 规则 |
|---|---|
| 元素 | 火 / 冰 / 雷 三系法术；敌人有元素标签与弱点 |
| 相克 | 打中弱点 → 伤害 ×2 且 +1 成功；同系 → 伤害 ×0.5；无标签 → 正常 |
| 咏唱 | 强力法术需咏唱：花 3 AP 起手，下回合才能释放；咏唱期间被打中 → 检定（决心+神秘学）DC 4，失败则法术位消耗且无效果 |
| 法术位 | 每场战斗 3 个法术位（阶段间恢复）；魔杖 +1 |
| 反噬 | 咏唱失败 2 次以上 → 「魔力反噬」，本场战斗智力检定 −1 |

> 体验目标：把「读条风险」和「看弱点」做成战斗解谜，而不是纯数值对拼。

**三阶段**：学院回廊（魔化学徒 · 石像鬼）→ 禁书库（禁咒残影 · 书架迷宫检定）→ 黑月祭坛（黑月化身 Boss · 裂隙倒计时 7 回合）。

**敌人**：魔化学徒（元素弱点随机）· 石像鬼（免疫同系）· 禁咒残影（模仿玩家技能）· 黑月化身（Boss，三系轮换）。
**物品**：魔杖 · 卷轴（一次性三系法术）· 魔力药水 · 禁咒残页 · 院长徽记。

---

### 3.5 世界 5 · 灰烬公路（废土 / 末世）

**世界观**：核战三年后，灰烬公路上只剩掠夺者、辐射犬与抛锚的装甲车。幸存者营地等着你把车修好。

**主线**：加油站取燃油与零件 → 穿越辐射峡谷 → 攻破掠夺者营地夺回装甲车。
**支线**：护送幸存者（不能死亡）· 回收 3 罐净水（营地民心）· 拆解 3 处废墟（装备改造）。

**独特机制 · 辐射与耐久**

| 机制 | 规则 |
|---|---|
| 辐射值 | 进入辐射区每回合 +1；战斗中使用「辐射武器」每次 +1；抗辐射药 −3 |
| 辐射惩罚 | ≥4：所有检定 −1；≥7：每回合掉 1 血且最大生命 −10%；≥10：进入「急性辐射病」，战斗结束前无法恢复 |
| 装备耐久 | 武器/护甲各 5 点耐久；每次攻击/被击中 10% 概率 −1（可用「修理包」+2） |
| 耐久归零 | 武器损坏 → 只能用拳头；护甲损坏 → 失去护甲值与防御加成 |
| 拾荒改造 | 在废墟花 2 AP 做「感知+调查」DC 3：成功获得零件，可为武器 +1 伤害或 +1 耐久上限 |

> 体验目标：稀缺感——子弹要数着用，装备会坏，辐射在追你。

**三阶段**：加油站（掠夺者 · 辐射犬）→ 辐射峡谷（辐射区 · 变异巨兽）→ 掠夺者营地（首领 Boss · 装甲车夺回）。

**敌人**：掠夺者（远程，掉落弹药）· 辐射犬（高速群）· 变异巨兽（高血高伤）· 掠夺者首领（Boss，护甲 2）。
**物品**：盖革计数器（显示辐射值）· 抗辐射药 · 修理包 · 燃油罐 · 猎枪（弹量 6）· 撬棍。

## 四、架构改造方案

### 4.1 现状的硬编码点（必须先拆）

| 位置 | 硬编码内容 | 影响 |
|---|---|---|
| `ui/hub.gd` | `SCENARIO_TITLE`/`SCENARIO_DESC` 常量、`_enter_scenario()` 写死 r001 路径、单张卡片 UI | 无法挂多世界 |
| `scenarios/r001_apartment/scenario.gd` | `preload` r001 的 map/content/dialogs；任务列表写死 3 个；`_inspect_spot()` 里每个调查点的效果**用 match 硬编码**（拿钢管、拿钥匙、加线索、开检定）；地图与出口写死 | 无法复用为通用世界场景 |
| `legacy/combat_scene.gd` | `preload` r001 的 `map_data.gd` 作为战场，玩家起始位置取自探索 | 战斗场地无法随世界切换 |
| `autoload/game.gd` | 只有 `pending_scenario_id` 单值、`scenario_state` 无世界维度 | 无法记多界进度 |

### 4.2 目标架构

```
world/
  registry.gd            # 世界注册表：id -> WorldDef，负责「列出五界 / 取某界 / 取某阶段」
  world_def.gd           # 世界定义的数据结构说明与构造助手
  w1_apartment/world.gd  # 惊变公寓：stages[] / quests / dialogs / settlement / mechanic
  w2_xianxia/world.gd
  w3_scifi/world.gd
  w4_magic/world.gd
  w5_wasteland/world.gd
rules/mechanics/
  mechanic_base.gd       # 机制钩子基类：on_combat_start / on_turn_start / on_damage / on_check ...
  noise_infection.gd     # 世界 1
  spirit_arts.gd         # 世界 2
  shield_intrusion.gd    # 世界 3
  element_cast.gd        # 世界 4
  radiation_durability.gd# 世界 5
```

### 4.3 世界定义数据结构（草图）

```gdscript
# 每个世界一份，纯数据；scenario.gd 只按它渲染与执行
{
  "id": "w2_xianxia",
  "name": "剑影仙途",
  "genre": "仙侠 · 修真",
  "rating": "C",
  "theme_color": Color(0.45, 0.75, 0.62),
  "intro": "……",
  "mechanic": "spirit_arts",            # 交给 rules/mechanics 的 id
  "quests": [ {id, kind, name, desc, hint_active, reward_points}, … ],
  "stages": [
    {
      "id": "gate",
      "title": "山门石阶",
      "tiles": ["####…", …],            # 地形表
      "spawn": Vector2i(2,2),
      "exit": Vector2i(18,10),          # 或 "objective": "boss"
      "enemies": [ {id, pos}, … ],
      "npcs":    { "elder": {pos, label, dialog} },
      "spots":   { "stele": {pos, label, actions: [
                     {type:"clue", id:"…", text:"…"},
                     {type:"check", attr:"per", skill:"investigate", dc:4,
                      pass:{give:"talisman"}, fail:{clue:"…"}},
                     {type:"dialog", npc:"elder"}
                 ]} },
      "transition": {condition:"quest_done:sword_crypt", next:"crypt", text:"…"}
    }, …
  ],
  "settlement": { "perfect": {…}, "normal": {…}, "death": {…} }
}
```

**关键改动**：`_inspect_spot()` 的 match 分支全部变成 `actions` 数据，由一个通用解释器执行（`clue` / `give_item` / `set_weapon` / `check{pass,fail}` / `dialog` / `open_stage` / `heal` / `damage`）。这样五个世界共用同一套交互代码。

### 4.5 存档升级

## 五、独特机制的实现钩子

所有机制挂在 `MechanicBase` 的同一组钩子上，`CombatManager` 与 `scenario.gd` 只调用钩子，不认识具体机制：

| 钩子 | 时机 | 世界 1 噪音/感染 | 世界 2 内息 | 世界 3 护盾 | 世界 4 元素 | 世界 5 辐射 |
|---|---|---|---|---|---|---|
| `on_world_enter` | 进入世界 | 感染度归零 | 满灵力 | 满护盾 | 法术位 3 | 辐射归零 |
| `on_turn_start` | 每回合 | 噪音衰减 | 灵力 +1 | 护盾 +1 | — | 辐射区 +1 |
| `on_attack` | 攻击前 | 开枪噪音 +3 | 消耗灵力加伤 | — | 元素相克修正 | 耐久判定 |
| `on_damage_taken` | 受击 | 抓伤 +1 感染 | — | 护盾吸收 | 咏唱打断 | 护甲耐久 |
| `on_check` | 检定 | 感染 ≥3 → −1 | — | — | — | 辐射 ≥4 → −1 |
| `on_combat_end` | 战斗结束 | 噪音清零 | 灵力保留 | 过载清除 | 法术位保留 | 辐射累积保留 |

这样新机制是「加法」：新增一个 `mechanics/xxx.gd` + 世界定义里写 `mechanic: "xxx"` 即可，不动核心。

## 六、分期计划与工作量

| 阶段 | 交付 | 工作量 | 验收 |
|---|---|---|---|
| **P0 架构** | 世界注册表 + 通用世界场景 + 数据驱动交互 + 存档 v2 + 机制钩子基类 | 4–5 人日 | 惊变公寓**迁移进新架构后六项测试全绿** |
| **P1 世界 1 升级** | 惊变公寓三阶段 + 噪音/感染机制 | 2–3 人日 | 三阶段可连续通关；机制单测通过 |
| **P2 世界 2** | 剑影仙途（三阶段 + 内息功法） | 4–5 人日 | 灵力系统可玩；Boss 倒计时可达 |
| **P3 世界 3** | 零号协议（三阶段 + 护盾入侵） | 4–5 人日 | 入侵检定链可用；智力流成立 |
| **P4 世界 4** | 黑月学院（三阶段 + 元素咏唱） | 4–5 人日 | 相克 ×2 生效；咏唱打断可复现 |
| **P5 世界 5** | 灰烬公路（三阶段 + 辐射耐久） | 4–5 人日 | 辐射惩罚与耐久损坏可见 |

## 七、风险与取舍

| 风险 | 说明 | 对策 |
|---|---|---|
| 架构重构破坏现有测试 | `scenario.gd` 739 行是核心资产 | P0 迁移后**必须先跑绿六项测试**再进 P1；通用解释器与旧 match 逻辑做等价性核对 |
| 内容量爆炸 | 五界 × 三阶段 = 15 张地图 | 地图模板化（公寓/峡谷/走廊/祭坛四种骨架复用），先保玩法差异再谈美术差异 |
| 机制叠加过载 | 玩家要同时记噪音、感染、灵力… | 每界只教 1 个机制；UI 只显示本界相关资源；跨界的机制互不生效 |
| 平衡崩塌 | 五界难度差异 + 自由进入 = 新手可能直接进 B 级世界 | 卡片明确标注评级与推荐属性；B 级世界首战给一次「主神提示」警告 |
| 存档膨胀与迁移 | v1 单副本存档 | 存档加 `version`，v1 自动迁移为 w1 进度 |
| 术语一致性 | 同一技能在五界的称谓不同（白刃 vs 剑诀） | 世界定义可覆盖显示名，底层 skill_id 不变 |

## 八、待用户确认的三点

1. **五个世界的题材与主线**是否认可（可替换任意一界，机制随题材调整）。
2. **是否按 P0 → P1 → 逐界 的顺序推进**，先在惊变公寓上跑通新架构与三阶段结构。
3. **是否现在开工 P0**（世界注册表 + 通用世界场景 + 存档 v2），完成后即可看到「五扇门」的主神空间雏形。
