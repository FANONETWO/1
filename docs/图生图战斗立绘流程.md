# 战斗立绘：图生图（img2img）工作流

> 背景：程序化绘制（Aseprite Lua 几何拼图）试了 4 版，**达不到火纹的手绘品质**。
> 改用**图生图**：以火纹原版素材为**结构参考**，让扩散模型重绘材质与细节，
> 再用脚本做**像素化后处理**（降色 + 描边），得到「火纹味」的**原创**立绘。

---

## 一、为什么用「低去噪强度」的图生图

| 参数 | 值 | 原因 |
|---|---|---|
| `denoise` | **0.5 ~ 0.7** | 太高会丢掉构图变成随机图；太低只是复读原图 |
| 参考图 | 火纹职业卡（`docs/art_reference/ref_*.png`） | 提供**专业构图**：前倾、垂臂、宽肩等 |
| 提示词 | 明确写 `fire emblem gba style, 16 colors, dark outline, white background` | 锁风格 |
| 后处理 | 降色 16 + 1px 描边 | **像素感的关键其实在这一步**，不在模型 |

> ⚠️ **版权**：参考图仅用于**提取构图特征**（姿势、比例、明暗层次）。
> denoise ≥ 0.5 时模型会重绘绝大部分像素，产出的是**新图**而非复制品。
> 但为稳妥，发布前建议改用 CC0 参考图或自绘参考。

## 三、工作流

```
参考图（火纹职业卡）
   │
   ├─ LoadImage → VAEEncode ─┐
   │                          ├─ KSampler(denoise 0.62, dpmpp_2m/karras)
   ├─ CLIPTextEncode(正向) ───┤
   └─ CLIPTextEncode(负向) ───┘
                              │
                        VAEDecode → SaveImage
                              │
                    pixelize_for_game.py
                    （抠背景 → 裁剪 → 缩放 64×96 → 降 16 色 → 描边）
                              │
                    assets/sprites/w1/battle/*.png
```

## 四、用法

```powershell
# 1) 启动 ComfyUI（另开一个窗口）
D:\1\ComfyUI_windows_portable\run_nvidia_gpu.bat

# 2) 批量生成 4 个立绘（丧尸 / 爬行者 / 尸王 / 主角）
cd D:\1\infinite_loop
python tools\pixelart\img2img_battle_sprite.py --batch

# 3) 单张 + 自定义提示词
python tools\pixelart\img2img_battle_sprite.py `
  --ref docs/art_reference/ref_revenant.png `
  --prompt "pixel art sprite of a rotting zombie, 3/4 side view facing left, fire emblem gba style, 16 colors, dark outline, white background" `
  --name zombie --denoise 0.62 --steps 26

# 4) 后处理（AI 原图 → 游戏素材）
python tools\pixelart\pixelize_for_game.py assets\raw\ai\zombie_raw.png zombie --size 64x96 --colors 16
```

### 调参建议

| 想要的效果 | 调整 |
|---|---|
| 更像原参考（构图稳） | `--denoise 0.5` |
| 更原创（细节多） | `--denoise 0.72` |
| 颜色更干净 | 后处理 `--colors 12` |
| 保留手绘描边 | 后处理去掉 `--no-outline`（默认加） |
| 背景抠不干净 | `--bg 255,255,255` 或 `--tol 45` |
