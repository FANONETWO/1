# 独狼模式奖励点 ×1.5，理由是风险对价

独狼（1 人出战）拿 ×1.5，小队（4 人）拿 ×1.0。

这不是「单机可怜补偿」，而是**风险溢价**：独狼没有人分摊伤害、没有救援、
失控了没人拦。因此配套三条：结算面板**明写**「风险溢价 ×1.5」；
**成绩按模式分开记**（键是 `scenario_id@mode`）；死亡不结算，也就没有倍率。

## Considered Options

- 不给倍率：独狼纯受苦，没人会主动选
- 给倍率但不写明：玩家会以为小队模式被折价，是暗箱
- 给倍率但成绩混记：独狼的 ×1.5 会永久霸榜，小队玩家再强也追不上，榜就废了

## Consequences

- 存档 `best_endings` 的键带模式后缀；v2 及以前的老档案迁移时统一归到 `@solo`
- 主神空间的「最佳评价」必须显示当前模式的记录，不能读全局
- 调平衡时改的是「小队变强」，不是「砍独狼倍率」—— 倍率是设定，不是参数
