# 行动条用 CTB（行动值）而不是实时 ATB

战斗的出手顺序由「行动值」决定：每个单位持有 `av`，越小越先动，行动后 `av += 1000 / speed`，
于是速度高的人出手更频繁。玩家能用**指挥点**干预顺序（「抢手」提前自己、「压制」推后敌人）。

评估过另外两种做法：**实时 ATB**（FF 式充能条）与本作「点击式回合制 + 单机垂直切片」
的操作节奏冲突，而且要重写整个回合流程；**纯显示顺序条**好看但不能干预，策略性提升最小。
CTB 让顺序**可见且可干预**，同时保住点击操作。

## Considered Options

- 实时 ATB：紧张，但逼人手忙脚乱，且推翻现有回合制
- 纯显示顺序条：只是装饰，玩家算得出但改不了
- CTB：顺序由行动值决定 + 指挥点可干预 ← 采用

## Consequences

- 「回合」的含义变了：回合数 = 最慢者的行动次数 + 1，快的人会在同一回合里多动一次
  （见 `GLOSSARY.md` 的「回合」）
- 「每回合一次」的资源（首击减伤、防御姿态、意志力限次）改成按**自己的回合**重置，
  否则出手快的人反而吃亏
- 战斗底部面板与行动条必须显示**同一个数值**（指挥点），
  不能一边读角色卡的个人基数、一边读战斗内的共享池（曾经因此显示成「战术点 0 / 指挥点 5」）
