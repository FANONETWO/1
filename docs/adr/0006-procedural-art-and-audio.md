# 美术与音频全部程序化生成，不引入外部素材包

9 种地形 tile、战斗立绘、19 个音效、3 首 BGM 全部由 `tools/` 下的 Python / Lua 脚本生成；
仓库里只有产物，没有 Aseprite 源文件，也没有素材包。UI 主题同样是代码构建的
（`AkTheme.build()`），不存在 `.tres` 主题文件。

三个原因：**版权干净**（原型期唯一的外部素材是标了 `{IS}` 的任天堂图，发布前必须替换）；
**可复现**（调色板、尺寸、合成规则都写在脚本里，重跑即得，不绑定某台机器上的美术工程）；
**不被管线阻塞**（没有美术资源也能推进玩法与数值）。

## Considered Options

- 买或下载素材包：快，但版权与风格统一都是债
- 先用占位素材、后期再替换：常见做法，但「后期」往往不来，最后带着侵权素材发布

## Consequences

- 想让某个 tile 或音效变样，**改脚本重跑**，不要手改 PNG / WAV（下次生成会覆盖）
- `assets/raw/`（生成中间物）与 `.secrets/` 不入库
- 这条决定限制了美术上限：像素细节受生成脚本能力约束。属已知取舍，
  真要突破时应当**先推翻这条 ADR**，而不是偷偷塞进一张手绘图
