# 视野锥是 90°，且敌人刚察觉你时先愣一回合

视野锥的判据是 `|d·f| ≥ |d×f|`（±45°），不是 `d·f > 0`（那是 ±90°，侧后方也算看见）。
敌人进入追逐后，**察觉你的那一回合原地不动**，下一回合才起步。

原因：视野半径与敌人移动速度共同决定「反应窗口」。曾经为了「潜行太难」把丧尸视野压到 2 格，
实机测出来正好相反：2 格内察觉、1 格接触、敌人一回合走一格 —— 三段挤在同一瞬间，
追逐形同虚设。潜行空间应该由**锥角（90°）与背后接近**来给，不是把视野勒到看不见；
愣一回合则是给玩家一个明确、可预期的反应窗口。

## Considered Options

- 视野半径 2：察觉即贴脸，追逐没有过程（已实机证伪）
- 视野半径 3 + 察觉当回合就动：玩家反应不过来，追丢计时也来不及生效
- 锥角收到 45° 以下：背后突袭太容易，敌人形同瞎子

## Consequences

- `_sight_cells()` 与 `_in_enemy_sight()` 必须用同一个锥形判据，
  否则会出现「看得到格子却看不到人」
- 视野锥的缓存签名必须含 uid + 位置 + 朝向 + 视野格数：
  只比 uid 的话，巡逻兵转身后锥会冻结在原地
- 亮红层（此刻会察觉你的敌人视野）画在迷雾**之上**，
  暗红预警层（其它敌人的视野）留在迷雾之下
