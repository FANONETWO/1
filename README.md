# 轮回回廊

**无限流题材的单机回合制 CRPG** ｜ Godot 4.7.2 · GDScript · 2D 像素

> 你被「主神」丢进轮回。第一场影片是深夜的公寓楼：
> 走廊里有东西在拖行，楼上有人一直没下班，而出口的消防门锁着。

![战斗界面](assets/screenshots/03_battle.png)

## 这是什么

一个**可玩的垂直切片**：一场完整的影片（约 20 分钟）——
建卡 → 主神空间 → 进入副本「惊变公寓」→ 探索 / 潜行 / 战斗 → 结算，全流程跑通。

## 玩法特性

- **D10 骰池检定**：掷「属性 + 技能」枚 D10，每枚 ≥8 计 1 成功，掷出 10 可追加一骰；成功数 ≥ 难度即通过
- **回合制潜行**：你行动一次，每个敌人各走一步。敌人有视野锥和朝向 —— **站在它背后就是突袭**
- **迷雾 + 已探索记忆**：只看得清 6 格内、且没被墙挡住的地方；走过的房间会留下暗色轮廓
- **噪音驱动的尸潮**：噪音到 6 / 10 / 14 分别招来逐尸 / 爬行者 / 尸群，安静几回合会自己衰减
- **AP 制战斗**：每回合 6 行动点（移动 1 格 1 点 / 攻击 3 点 / 防御 2 点），带火纹式特写演出
- **血统系统**：十系 × D→S 五级 × 四层节点；排斥度过高会触发**「血脉失控」**
- **九属性皆有战棋出口**：力量→近战伤害、敏捷→移动力、耐力→生命、感知→暴击、操控→威慑……
- **12 个箱庭地图**：RE2 式单房间箱庭，走到门格换房间（不换场景），战斗与掉落状态跨房间保留
- **程序化音画**：9 种地形 tile、19 个音效 + 3 首 BGM 全部由脚本生成，不依赖外部素材

## 快速开始

```powershell
$godot = "你的 Godot 4.7.x 可执行文件路径"
Set-Location <项目目录>

& $godot --headless --path . --editor --quit   # 首次必做：注册 class_name
& $godot --path .                              # 开玩：主菜单 → 新的开始 → 建卡 → 主神空间 → 进入副本
pwsh -File tools/run_tests.ps1                 # 全部 31 项测试（带超时与时间戳）
```

## 项目结构

```
autoload/  全局单例（状态 / 日志 / 音频）
data/      纯数据表（属性、技能、敌人、物品、血统…）
rules/     规则逻辑（骰池、角色、战斗结算、任务）
world/     地图逻辑 + 寻路 + 世界注册表 + 渲染器
battle/    战斗界面与演出
ui/        界面与入口场景
scenarios/ 副本实现（r001_apartment）
assets/    地形 / 立绘 / 音频 / 截图
tests/     31 项测试 + 时间戳看门狗
tools/     一键测试、美术与音频生成、开发脚本
legacy/    退休代码归档
docs/      设计 / 剧情 / 试玩报告 / 开发文档
```
