# legacy —— 退休代码归档

> **这个目录里的东西不参与游戏运行，也不应该被新代码引用。**
> 保留它们只是为了「想查旧实现时还能查到」；真要复用请先想清楚为什么，并把它
> 按现行分层（`rules/` / `world/` / `battle/` / `ui/`）重写一遍。

## 为什么放在这里而不是直接删

`git log` 里能翻到，但翻起来麻烦。归档在同一个目录 + 这份说明，
比留在主目录里冒充"在用代码"要诚实得多，也比删掉更容易回答
"当时那套是怎么写的"。
